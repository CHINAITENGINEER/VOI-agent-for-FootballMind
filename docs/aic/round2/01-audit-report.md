## 五、统计方法学审查结论

| 审查项 | 结论 | 依据 |
|---|---|---|
| AUC 标签衡量什么？ | **人工判读的"标题是否含本场预测相关信息"**（相关性），不是收益方向，也不是信息价值 | `exp2_ranking.json` → `menu_labels.json` 判读规则；`bench_lib.py` |
| 0.544 与 0.918 是否同一目标？ | **是同一标签、同一子集**（Inter 39 条），但**都不是 g 的训练目标** | 同上；g 的训练目标是 `signed_gain` |
| 近常数输出能证明什么？ | 能证明「在该输入分布上，g 对候选的**区分力**极小」（跨度 4.4e−3，std 8.1e−4）。**不能**证明「g 的预测精度差」或「信息价值不可估」 | `g_baseline_inter.gain_min/max/std` |
| 基线/编码器是否同一划分？ | **是**。同一 `splits.json`、同一标准化器（仅训练折拟合）、同一 Ridge 读数、同一评测口径（比赛等权 macro MSE） | `exp1_summary.json`；`audit_crosscheck` 700/700 零误差 |
| 35 切分有多少是独立的？ | **只有 3 个 LOCO 与 1 个 chrono 具有跨来源/时间意义**；30 个 rand 共享同一批比赛，**不独立** | `readable-report.txt` §L1；`acceptance-notes` 亦自述"重复划分不是 30 个外部测试集" |
| 置信区间的计算单位？ | **比赛**（`physical_match_id`），比赛等权；bootstrap 在比赛级重采样 | `16-paired-bootstrap.py`；`exp1_paired_bootstrap.json` |
| 测试集是否被看过？ | **是**。51 场中的原 val/test 18 场已被此前多轮审计使用；`postread-reversal-corrected` 自述"全部是已查看历史数据上的开发诊断，不是新盲测" | 多处自述；属透明披露，非隐瞒 |
| 未来信息泄漏？ | **无法完整排除**：仅 11/51 场有精确 UTC kickoff，123 行 `time_unknown`（含原验证/测试 48 行）。代码层面 `resolve()` 已强制 `published > cutoff` 抛错，但**时间戳本身的可信度未建立** | `postread-qwen-stability` 状态审查；`entity_evidence_updates.py::resolve` |
| 同源转载重复计数？ | **已部分处理**：`_digest` 去重 + 同源同实体后继文档超越规则 + 冲突保留。**但无系统性血缘图去重** | `entity_evidence_updates.py`；`state_candidate_gain.py` L58 |
| 标签生成偏差？ | **存在已知偏差**：35 状态列恒零、11 候选列恒零、零收益占 39.4%；且 gain 依赖冻结 f，f 的缺陷会直接传导为标签噪声 | `READ_FIRST.txt`；`postread-qwen-stability` |
| 「无文本配置优于恒零」与 GTE CI 结果是否一致？ | **一致但需精确表述**：35 切分均值上无配置优于恒零；**唯一** 90% CI 完全低于两条基线的是 GTE-small 正文臂（−5.85e−5 / −6.05e−5）。二者不矛盾——前者是均值排序，后者是单臂的配对检验 | `exp1_summary.json` + `exp1_paired_bootstrap.json` |
| 「负结果可成为研究贡献」是否过度推断？ | **有条件的成立**。成立的三个条件：① 有可复核的对照协议；② 边界在文献中未被报告；③ 给出可复用的诊断而不是单纯的"我的模型不行"。第 ③ 条目前**部分满足**（有协议但缺消融），须在方案中如实说明 | 本轮文献核验（EVSI 类工作均在大样本/模拟中验证）；`postread-reversal-corrected` 交付的完整诊断脚本 |
