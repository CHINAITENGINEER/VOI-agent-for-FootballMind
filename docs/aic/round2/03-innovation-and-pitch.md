## 一、最终定位

**定位：一种具有明确研究问题的系统性研究原型（不是新算法，不是对现有算法的局部改进）。**

推荐的一句话定义：

> FootballMind 研究的是「一个已有初步概率判断的决策系统，如何判断自己还缺什么信息、哪条信息值得付出成本获取、以及何时应该停止」。我们在真实足球情报环境下实现了这一闭环，并用 51 场真实比赛、92 篇真实新闻、289 条状态转移，**量化了条件信息价值估计在极端小样本真实文本环境下的失效边界**。

### 为什么是这个定位（四条，按重要性）

1. **代码实际支持的**：完整的 f/g 接口、硬预算、证据超越与冲突保留、方向性准入契约、零网络回放、SHA 绑定。**不支持的**：任何形式的算法原创性、最优性、跨域能力。
2. **实验真正证明的**：一个可复核的负结果（无文本配置优于恒零基线；验证集选模型在测试上落后基线）与一个唯一的弱正向信号（GTE-small 正文臂 CI 不含 0；P0 上收缩后相对不查询平均差 −0.01185）。
3. **前人已覆盖的**：VoI（1966）、EVSI 回归（2015/2019）、预算化非短视信息价值（2005）、元推理停止（1991）、按需检索（2023）、多轮检索停止 Critic（2025）、以及**两个 2026 年的完整足球自主检索预测系统**。
4. **剩下的可辩护增量**：见下 §二。**只有 2 个，不凑第 3 个。**

## 二、最终创新点（2 个）

### 创新点 1（主）：条件信息价值估计在极端小样本真实文本环境下的失效边界

| 项 | 内容 |
|---|---|
| **正式名称** | 条件信息价值估计的失效边界刻画（Failure-boundary characterization of conditional value-of-information estimation） |
| **要解决的具体问题** | 当训练样本极少、来源高度集中、标签零值占比高、特征列半数恒零、且文本含身份捷径时，一个以领域特征监督训练的信息价值估计器会退化成什么？退化在什么条件下发生？如何证明它不是随机波动？ |
| **现有方法的不足** | EVSI 回归估计（Strong 2015、Heath 2019）与现代贝叶斯实验设计（Rainforth 2024）均在**模拟或大样本**中验证；自适应检索门控（Self-RAG、FLARE、SIM-RAG、DynaKRAG）以 LLM 内部状态为准，**不报告退化边界**；足球领域的两个 2026 前瞻系统（WC2026-Agents、WorldCupArena）做了完整链路，但**未做小样本退化分析**，且只比较"给/不给检索"两档 |
| **我们的实际机制** | 在 A 集（51 场 / 92 篇 / 289 行）上，以统一的读出协议（Ridge，比赛等权 macro MSE，alpha=10 及验证选 alpha 两档）、35 种切分（P0 / chrono / 3×LOCO / 30×rand）、8 个编码器（含 4 个冻结预训练模型）、7 个特征臂，系统性测量条件信息价值回归的退化 |
| **与最接近的前人工作的区别** | **不是提出新估计方法，而是给出方法失效的边界条件与可复核的诊断协议**；并引入"验证集选模型 → 测试落后基线"这一代价的量化，以及队名掩码 / 收缩 / 来源留出三类消融 |
| **当前实现证据** | [state_candidate_gain.py](file:///d:/a1-%E8%B6%B3%E5%BD%A9/football_research/acquisition/state_candidate_gain.py)（g 的 15 特征 + Ridge）｜`E:\FootballMind\experiments\postread-clean-expansion-20261025-v1\`（数据集与脚本）｜`var\work\fm-embedding-bench-20261025-v1\`（35 切分 × 8 编码器基准）｜`E:\...\postread-reversal-corrected-20261025-v2\`（修正版 + 收缩）｜`E:\...\postread-shortcut-ablation-20261025-v1\`（标题消融）｜`E:\...\postread-qwen-stability-20261025-v1\`（语义编码器稳定性） |
| **实验依据（全部可复核）** | ① 统一读出下，**8 个编码器 × 7 个特征臂共 56 个文本配置，在 35 切分均值上无一优于恒零基线**（最低 0.00094081 vs 恒零 0.00089320）；② 标题通道有害：原标题 test MSE 0.0021539，替换为训练均值后 0.0014257（同一模型验证集上 0.0007747 为全场最优）；③ 验证集最优模型在 P0 测试上落后恒零 **0.000935**；④ 30 次随机重排在"实际有效模型"上选出 **15 种不同模型**；⑤ Qwen32 MLP 在 **6/6 组**均未低于恒零基线，6 组比赛配对 bootstrap **全部跨 0**；⑥ g 在真实菜单上输出近常数（`gain ∈ [0.019519, 0.023954]`，跨度 0.004435，std 0.000812）；⑦ 收缩修复中 **6 组有 3 组验证选权为 0**（文本通道完全退化到常数基线）；⑧ 来源集中度 57%（`leedsunited.com` 166/289）；⑨ 特征退化：57 状态列中 35 列恒零、29 候选列中 11 列恒零；⑩ 标签零值占 39.4%（正 60 / 零 114 / 负 115） |
| **目前不能作出的结论** | ❌「所有信息价值估计方法都失效」（只测了 8 编码器、2 种读出、1 个目标函数）；❌「这是全球首次」（只能说"在本人检索范围内未找到"）；❌「g 的预测精度是 0.544」（目标不等价）；❌「该边界可外推到其他领域」 |
| **评委最可能的反驳** | 「负结果不是创新」「你的模型不行，跟别人有什么关系」「51 场太小，说明不了任何问题」「AUC 对比目标不一致」 |
| **对应回答与证据位置** | 见 §四 问答手册 Q3、Q9、Q17；证据：第 3–4 页 PPT |
| **必须补充的实验** | ① 对照臂：把通用语义排序器（Qwen3）作为选片策略臂接入现有策略比较（见 §五）；② 低方差弃权机制（未实现）；③ 校准指标（ECE 未做） |

### 创新点 2（次，明确标注为待验证）：可审计的保守证据准入契约

| 项 | 内容 |
|---|---|
| **正式名称** | 四项联合证据准入契约（Quadruple-conditioned evidence admissibility contract） |
| **要解决的具体问题** | 新闻里"某球员正在康复训练"这类句子，是否足以改变预测？如何防止把"状态描述"误当成"影响方向证据"？ |
| **现有方法的不足** | Self-RAG 用反思 token 判"是否被支持"；EDL 用证据量判"是否弃答"；**两者都不区分「信息存在」与「信息具有可归因的方向性影响」** |
| **我们的实际机制** | [directional_evidence.py](file:///d:/a1-%E8%B6%B3%E5%BD%A9/football_agent/directional_evidence.py)：在保留 `supports/refutes/no_answer` 的同时，额外要求**方向标签 + 主体 + 方向依据 + 逐字引文**四项同时成立；"正在康复/训练/可能出场"被记录为 `unknown + availability_only`；该扩展**默认不进入数值求解器**，只有完成方向性似然校准并升级模型版本后才允许影响后验 |
| **与最接近的前人工作的区别** | ① 门控维度从"是否被支持"升级为"是否存在可归因的方向性影响"；② 保守性写入类型系统（未知即未知，不赋零值）；③ 影响后验需显式版本升级而非默认开启 |
| **实现证据** | `football_agent\directional_evidence.py`；`var\submission\p7-historical-semantic\mechanism-03\audit.json` |
| **实验依据** | `mechanism-03` 在真实历史面板上：5 条观察 → 1 条 `supports + match_specific`、4 条 `no_answer`；唯一支持项使后验从 53.4884% / 30.2326% / 16.2791% 变为 50.7306% / 31.0413% / 18.2281%。**这证明了代码路径真实运行。** |
| **目前不能作出的结论** | ❌「门控降低了错误更新率」（**从未做过消融**）；❌「2.8pp 的概率变化是真实信号」（未经校准，可能为噪声）；❌「方向判断可靠」（来自冻结语义模型假设） |
| **可行性说明（重要）** | 门控消融**当前不可行**：面板只有 5 条观察，5 臂消融等于每臂 1 条，无统计意义。因此本创新点只能作为**设计贡献**陈述，不得作为**已验证结论**陈述 |
| **评委最可能的反驳** | 「这只是工程约束，不是算法」「方向还是 LLM 判的，绕回来了」「没有任何消融，凭什么说是创新」 |
| **对应回答与证据位置** | 见 §四 Q10；证据：PPT 第 7 页 |

### 为什么不设第 3 个创新点

| 候选 | 判定 |
|---|---|
| 两步前瞻（发现动作的后续价值） | **不保留**。同表内固定顺序全查的纯 log loss 优于两步 VoI（0.900448 vs 0.908912）；设计缺陷导致"固定 = 随机"，不足以证明多工具排名能力 |
| 多智能体协作 | **不保留**。自述为开发效率收益，未建立产品收益；MAST 亦不支持默认增益假设 |
| 零网络回放与 SHA 绑定审计 | **不保留为算法创新**，仅作为工程与可复现性材料 |
| 2179 篇扩展语料 | **不保留**。缺逐篇适用性与同一 f 的收益标签，不能称现成训练行 |
| 收缩修复 | **并入创新点 1** 作为诊断手段，不单列（3/6 组选权为 0，说明其本身就是"文本无增量"的证据） |

## 四、完整中文讲稿

### 5 分钟正式答辩讲稿

**S1（第 1 页，25 秒）**

> 我们的项目叫 FootballMind。它研究的不是怎么预测比分，而是：**当一个决策系统已经有了初步的概率判断，面对不断出现的新信息，它怎么判断自己还缺什么、哪条信息值得付出成本去拿、以及什么时候该停下来。**
>
> 用户只输入一场比赛。系统要自己完成六件事：生成候选、估计价值、实际获取、准入判断、更新概率、然后重新决策或者停止。

**S2（第 2 页，30 秒）**

> 我们从一个具体矛盾开始：**能检索到更多信息，并不等于能做出更好的判断。**
>
> 这不是口号。我们在 5 场独立比赛的菜单上做了人工判读：**202 条候选里只有 22 条包含本场预测相关信息**，另有 14 条是有争议的边界项。其中一场 141 条候选中，只有 36 条是文章，105 条是站点导航链接。
>
> 还有一个更麻烦的：菜单里有一条去年同一对阵的旧稿，所有语义模型都把它排进前十四名——**只有时间戳能排除它。**

**S3（第 3 页，35 秒）**

> 所以我们想训练一个函数，判断"这篇新闻值不值得读"。然后我们做了一件在比赛里不太常见的事：**我们没有只报好消息，而是先证明它不行。**
>
> 我们在 51 场真实比赛、92 篇真实新闻、289 条状态转移上，用了 35 种数据切分、8 个编码器——包括 4 个冻结的公开预训练模型——和 7 种特征组合，一共 56 个文本配置。指标是比赛等权 macro MSE。
>
> 结论是：**没有任何一个文本配置，在 35 个切分的平均意义上，优于恒零基线。** 最低的配置是 0.00094081，恒零是 0.00089320。
>
> 需要说明两点：这 35 个切分共享同一批比赛，**不是 35 次独立实验**；而且我们做的是参数复现校验，700 个对照点与既有审计逐点一致，那只证明两次计算口径相同，不证明模型有效。

**S4（第 4 页，40 秒）**

> 那我们怎么知道这不是偶然？我们做了四件事。
>
> 第一，**标题消融**：把标题换成一个常数，测试误差反而从 0.0021539 降到 0.0014257。也就是说标题在这个切分上是**有害**的——而同一个模型在验证集上误差 0.0007747，是全场最好。这是验证-测试反转最干净的单点证据。
>
> 第二，**按验证集选模型的代价**：选出来的模型在测试上比恒零基线差 0.000935。
>
> 第三，**30 次随机重排**，最终选出的"有效模型"散布在 **15 种不同模型**上，其中还包括直接退化成常数基线的情况。
>
> 第四，我们把模型换成 **Qwen3-Embedding 加 MLP** 重做一遍：**6 个分组里 0 个优于恒零基线**，6 组的配对 bootstrap 区间**全部跨过 0**。
>
> 所以我们的判断是：**在这个数据规模上，瓶颈不在模型容量，而在监督信号和特征表示的错配。** 有几条直接证据：57 个状态特征里有 **35 个恒为零列**；289 行标签里**零收益占 39.4%**；9 个来源域名里**一个占了 57%**。

**S5（第 5 页，30 秒）**

> 说完问题，说系统。用户只输入一场比赛，系统在**硬预算**下运行：最多 10 次来源请求、5 次正文读取、5 次模型调用、15 分钟超时，每轮最多批准 2 个新域名。
>
> 这里要澄清一点：**LLM 只负责语义抽取和分类，选择和停止是数值策略和确定性代码。** 我们不把"多智能体协作"当作算法贡献——那在开发期提高了效率，但没有建立产品层面的收益。

**S6（第 6 页，35 秒）**

> 核心机制是两个公式。一步价值是当前风险减去期望的更新后风险，再减去成本；两步价值再加上"目录页本身不改变概率、但可能引出有用正文"的后续价值。
>
> **这里我必须同时报不利的结果**：在合成环境、预算 0.095 下，两步策略的损失加成本是 0.947120，优于固定顺序的 0.980864；**但如果只看纯预测损失，固定顺序反而更好——0.900448 对 0.908912。**
>
> 而且那个实验只有一个初始发现动作，所以固定和随机策略是等价的——**这不足以证明多工具排序能力。**

**S7（第 7 页，30 秒）**

> 第二个机制是证据准入。一条正文只有在**方向标签、主体、方向依据、逐字引文**四项同时成立时，才被允许影响后验。"某球员正在康复训练"这种只有状态没有方向的句子，会被标记为未知，不改概率。
>
> 在真实历史面板上，5 条观察里只有 1 条通过，后验从 53.49/30.23/16.28 变成 50.73/31.04/18.23。
>
> **但我要明确说：这个判断来自冻结的语义模型，没有校准；而且这个扩展默认不接入数值求解器。我们也没有做过门控消融——因为面板只有 5 条观察，做消融没有统计意义。**

**S8（第 8 页，25 秒）**

> 真实前瞻运行我们做了三场，共 8 次真实请求。克罗地亚对西班牙那场读到了官方正文，从内容产生了一条关于 Budimir 的后续查询并实际执行——**那条请求失败了，我们把它留在记录里。**
>
> 三场的概率都没有改变，赛果在冻结记录里仍然待结算。**我们把它作为工程闭环展示，不作为预测收益的证据。**

**S9（第 9 页，20 秒）**

> 我们把所有主张分成了四级：已实现、已验证、待验证、不应宣称。比如"完整闭环"是已实现的，"无文本配置优于恒零"是已验证的；"门控降低错误率"是待验证的；而"已提高准确率""已实现最优停止""跨语言能力"——**这些我们不宣称。**

**S10（第 10 页，30 秒）**

> 前人工作我们必须讲清楚。信息价值理论是 1966 年 Howard 提出的；用回归估计期望样本信息价值是 2015 年之后的成熟方法；预算约束下的非短视信息价值 2005 年就有次模近似；元推理的停止判据 1991 年就有；按需检索和"何时继续检索"分别是 2023 和 2025 年的工作。
>
> 更要紧的是：**2026 年已经有两篇论文，在足球赛前预测上完整跑了"自主检索—概率预测—赛后评估"的闭环。其中一篇的摘要明确写着：四个前沿模型在 92% 的场次给出相同首选，没有一个超过市场的 Brier 分数。**
>
> 所以我们不主张超越市场，也不主张这些机制的首创。

**S11（第 11 页，25 秒）**

> 我们保留了 2 项贡献。第一项是**条件信息价值估计的失效边界刻画**——包括那 56 个配置的基准、标题消融、30 次重排分布和收缩诊断。第二项是**可审计的证据准入契约**，但它目前是待验证的设计。
>
> 交付上，我们给出可运行后端、零网络回放、SHA 绑定的封版证据表和完整的 35 切分基准代码，别人可以直接复算。

**S12（第 12 页，20 秒）**

> 最后是局限。**最要紧的一条：我们还没有和"同类先进算法"做同条件对照**——比如把通用语义排序器作为一个选片策略臂接进现有比较。这是我们下一步第一位要补的实验。
>
> 其次是策略评估口径下的正式 g 训练行为 0、跨语言零实验、停止规则没有理论保证。
>
> 我们想验证的最终问题是：机器能不能在当前信息状态下判断什么值得继续查，而不是让人替系统写下每场比赛的调查清单。谢谢。

### 3 分钟压缩版

保留第 1、2、3、4、10、11、12 页，讲稿如下：

> **（25s）** FootballMind 研究的不是比分预测，而是一个已有初步判断的决策系统，如何判断自己还缺什么信息、哪条值得付出成本获取、何时停止。用户只输入一场比赛。

> **（45s）** 我们本打算训练一个"值不值得读"的函数，结果先证明了它不行。在 51 场、92 篇、289 行上，35 种切分、8 个编码器、7 种特征臂，共 56 个文本配置，**没有一个在平均意义上优于恒零基线**。为确认不是偶然：标题换成常数后测试误差反而下降；按验证集选模型在测试上落后基线 0.000935；30 次重排选出 15 种不同模型；换 Qwen3 加 MLP 重做，6 个分组 0 个优于恒零，bootstrap 全部跨 0。
>
> **（35s）** 直接证据是：57 个状态特征里 35 个恒零列、标签零收益占 39.4%、9 个来源里一个占 57%。**瓶颈不在模型容量，在监督信号与表示的错配。**
>
> **（30s）** 前人工作我们如实说：信息价值理论 1966 年就有，回归估计 2015 年成熟，预算化非短视信息价值 2005 年有近似，元推理停止 1991 年有判据。**2026 年已有两篇论文在足球上完整跑了自主检索加预测加赛后评估，其中一篇明确报告四个前沿模型无一超过市场 Brier。** 我们不主张首创，也不主张超越市场。
>
> **（20s）** 我们保留 2 项贡献：失效边界刻画、可审计证据准入契约（后者待验证）。交付包括可运行后端、零网络回放、SHA 绑定证据表与完整基准代码。
>
> **（15s）** 最大缺口是**还没有与同类先进算法的同条件对照**——这是我们下一步第一位要补的实验。谢谢。

## 五、最值得补做的实验（选定方案，替代抽象的"补市场赔率对照"）

### 5.1 三个候选改进方案的评定

| 方案 | 解决的问题 | 数学定义 | 与现有实现差异 | 需要的数据 | 最小可行实验 | 是否值得赛前实施 | 判定 |
|---|---|---|---|---|---|---|---|
| **A 保守的价值估计（收缩 + 低方差弃权）** | g 输出近常数时，微小差异被当成可靠排序 | `ŝ' = w·ŝ + (1−w)·b`，`w` 仅验证集选；或弃权规则 `若 std(ŝ) < τ 或 ‖ŝ‖₁ < ε 则输出"不可区分"` | 收缩**已实现**（toward_zero / toward_train_mean / toward_source_mean）；弃权**未实现** | 已有 A 集 | 已在 `postread-reversal-corrected-20261025-v2` 完成 | 部分 | **部分保留**：收缩结果已拿到（6 组中 3 组选权为 0），弃权机制不单独立项，并入方案 C 的一个臂 |
| **B 证据准入消融** | 四项条件是否各自必要 | 错误更新率 `P(更新 ∣ 证据无效)`；5 臂（全约束 / 去方向 / 去主体 / 去依据 / 去引文 / 无门控） | 门控**已实现**；消融**未做** | 需 ≥30 条以上有争议观察 | 面板**仅有 5 条观察** → 每臂 1 条 | ❌ **不可行** | **放弃**，明确说明样本量不足 |
| **C 成本约束下的选片与停止：接入"同类先进算法"对照臂** | 官方「实验验证 20 分」硬性要求"对比多个同类先进算法"，当前策略对照缺此臂 | 策略族 `Π = {不查询, 固定顺序, 随机, 通用语义排序(Qwen3), g, g+收缩}`；统一在 `M` 个候选池中选 top-k（k ≤ 2），比较最终 log loss 与 `loss+cost` | 现有策略比较器**已有 4 臂**（`no_information` / `random_exact` / `all_candidates` / `validation_selected`）；**缺的就是把冻结的 Qwen3 相似度作为排序分数接进去** | **全部已存在**：`postread-qwen-semantic-20261025-v1\embeddings.npz`（110×1024）、`postread-reversal-corrected-20261025-v2\run-script.py` | 在 6 个命名切分 + 30 次重排上运行 6 臂对照，验证集选参、测试集只报告一次 | ✅ **值得** | **选定** |

### 5.2 选定方案 C 的完整规格

| 项 | 内容 |
|---|---|
| **要解决的问题** | 当前策略对照里没有"通用大模型语义排序"这一臂，因此无法回答官方要求的"与同类先进算法对比"，也无法回答评委必问的"为什么不用一个强模型直接读"。 |
| **数学定义** | 令候选池为 `M`，每场最多采用 `k = 1` 或 `2` 篇。策略 `π ∈ Π` 给出排序分数 `s_π(a)`；采用 `top-k(M, s_π)`。策略损失为加入所选正文后的最终 log loss（比赛等权）。报两档：纯 log loss 与 `log loss + λ·cost`。 |
| **算法流程** | ① 复用 `postread-reversal-corrected-20261025-v2` 的数据与切分；② 对每个切分，仅在训练折拟合排序分数所需的标准化；③ 六个臂各自在验证折选参（收缩权重 / k / 阈值）；④ 测试折只评估一次；⑤ 报告每场比赛的配对差与 95% bootstrap 区间。 |
| **与现有实现的差异** | 现有 4 臂中，`validation_selected` 用的是**已训练的信息价值回归器**；新增臂使用**冻结的通用文本嵌入相似度**（Qwen3-Embedding-0.6B，revision `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`），**不做任何微调**。 |
| **与前人方法的差异** | DynaKRAG / SIM-RAG 用可学习控制器决定"是否继续检索"；本实验在同一信息池、同一预算、同一初始预测下，**比较"用什么标准选片"**，而不是"是否检索"。 |
| **需要的训练数据** | 无需新数据。需要：A 集 289 行、已有的 110 个 1024 维 Qwen3 向量、`splits.json`。 |
| **最小可行实验** | 在 6 个命名切分（P0 / chrono / loco×3 / global_time_51）+ 30 次重排上运行 6 臂；每场最多 1 篇与 2 篇两档；验证选参、测试一次。 |
| **成功标准** | ① **无论哪个臂胜出都算成功**——这是完成官方要求的对照，不是争胜负；② 若 Qwen3 臂显著优于 g 臂，结论为"通用语义排序器在本任务上优于轻量领域特征估计器"；③ 若 g 臂与 Qwen3 臂差异的 CI 跨 0，结论为"两者在本规模上不可区分"；④ 若某个臂在 ≥5/6 个切分上优于 `no_information` 且配对 CI 不含 0，则该臂值得作为后续基线。 |
| **失败判定** | 若全部臂都不优于 `no_information`（当前最可能的结果），则明确报告"在本数据规模下，任何选片策略都不优于不查询"——这与现有证据一致，且**是可交付的结论**。 |
| **数据泄漏与评估偏差** | ① 所有标准化/收缩权重**仅在训练折或验证折拟合**；② 测试折只评估一次，不得据测试结果改臂；③ A 集 51 场已被多轮审计使用，**属可见性偏置**，必须在结论中声明；④ 30 次重排共享同一批比赛，**不构成 30 次独立验证**；⑤ Qwen3 向量的截断（512 token，92 篇中 35–36 篇被截断）须披露。 |
| **是否赛前实施** | **是**。全部素材已存在，不需要新数据、不触碰冻结模型、不重算历史标签。 |

### 5.3 为什么这个方案优于第一轮建议的"补市场赔率对照"

| 维度 | 市场赔率对照 | 本方案 C |
|---|---|---|
| 所需数据 | B 集 290 场 + 可信的赛前时点赔率 | **已全部存在** |
| 时点可信度 | `quote_observed_at` 全部 UNKNOWN、`point_in_time_verified` 全部 false，需先解决 | 不涉及 |
| 触及官方评分点 | 间接（基线的说服力） | **直接命中「对比多个同类先进算法」** |
| 结果价值 | 若劣于市场则与 WC2026-Agents 重复 | 给出"轻量领域估计器 vs 通用语义排序器"的清晰界限，**文献中未见** |
| 违反禁令风险 | 需重算标签或改预算，风险高 | 零 |

**结论：本方案是唯一"素材齐备 + 直接对应评分表 + 无论成败都有结论"的实验。**
