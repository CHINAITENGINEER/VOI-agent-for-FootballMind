# FootballMind 主张、证据与限制

本清单用于检查申报书、演示、答辩和对外介绍是否与冻结产物一致。范围是 Round181 后端研究原型；未假定任何具体 AIC 赛事评分、奖金、截止日或录取标准。

## 可以支持的表述

| 主张 | 可核验的证据 | 必须同时说明的范围 |
|---|---|---|
| 用户提供比赛后，程序能够产生并执行信息候选 | Round180 三场真实执行：官方身份、来源入口、实际发现链接及一条内容衍生查询 | 当前入口只覆盖已经绑定的三场及明确配置的来源；不能称任意自然语言比赛都能正确解析 |
| 已读历史能够改变查询的模型条件价值 | Round178 同一伤病查询净值 +0.356163 / −0.074882 | 合成情境，来自设计的信号过程；不是对真实伤病影响的估计 |
| 相同相关信息不必重复产生收益 | Round178/179 的设计转载在取得原文后 EVSI 为 0 | 转载由模拟器构造；尚未证明开放文本中的通用事实去重与来源依赖识别 |
| 一步没有直接价值的发现动作，可以具有正的后续价值 | Round179 发现动作一步净值 −0.025，competitive 情境两步值 +0.248006077562 | 冻结请求类近似、两步前瞻、有限转移；不是任意长滚动策略的精确价值 |
| 有限策略可以节省查询并改善模拟综合目标 | Round179 预算 0.095：两步 loss+cost 0.947120，固定/随机 0.980864 | 固定/随机纯 log loss 更低；模拟成本不是真实货币；一个初始发现动作不足以证明一般工具排名能力 |
| 未知价值没有被写成零 | `TextReturnModel`、`DiscoveryReturnModel` 的 unknown 与受限子策略输出 | 已支持正收益分支可执行，但未解决所有未知；没有开放世界覆盖或最优性证明 |
| 实际新内容能够产生下一步行动 | 克罗地亚官方正文产生 Budimir 后续查询并实际执行 | 由词表和确定性证据提取产生；查询失败；上下文需要进一步绑定，未确认阵容事实 |
| 真实原始字节能够重建完整决策 | Round180 三份真实记录八份返回与旧记录零网络回放 | 可复现性是工程结果，不能替代模型正确性或因果收益证据 |

## 不应写入当前申报结论的表述

| 不受当前证据支持的表述 | 准确表述 |
|---|---|
| “首次提出 Agent 主动获取信息／首次将 VoI 引入 AI” | 基于已有 VoI、主动特征获取和工具 Agent 研究，验证具体的条件响应与有限候选发现机制 |
| “真实足球数据证明算法准确率或决策收益显著提升” | 历史单请求预算有微小纯损失改善，主预算仍有负结果；真实赛前仅完成有限探索与获取闭环，策略收益尚未建立 |
| “Agent 完全替代所有人工特征、语义和来源设计” | 用户无需逐场给调查清单；来源配置、词表、文本表示及候选规则仍有人为设计 |
| “LLM 已学会自主理解比赛并选择最佳工具” | 本版实测路径是数值模型与确定性工具；尚无 LLM 自主语义研究的对照证据 |
| “多 Agent 协作本身形成算法创新” | 并行开发提高开发效率；产品多 Agent 对照收益未在本版建立 |
| “MCP 或更多爬虫就是创新” | 它们是工具与数据接入手段，不作为研究原创性证据 |
| “已经穷尽信息，确认没有必要继续搜索” | 只能在声明的有限完整菜单下停止；未知或候选不完整时暂缓，物理预算耗尽时终止 |
| “高置信度／已经校准的风险等级” | 当前报告模型条件概率、支持状态和未知项；真实校准与参数不确定性尚未成立 |
| “一项价值为正的查询必然改善结果” | 正值是模型下的期望；单次结果可能变差，模型失配还可能导致平均收益为负 |
| “可直接迁移金融、医疗、自动驾驶” | 这些是可能的后续应用，需要重新定义损失、工具、身份与时间契约，并重新验证 |
| “AIC 已就绪／符合某项赛事／可保证获奖” | 通用算法创新赛研究原型材料已准备，具体赛事规则和完整效果要求尚未核对 |

## 样本与指标口径

| 证据组 | 独立样本单位 | 实际能回答的问题 |
|---|---|---|
| Round178 条件正文模拟 | 900 训练 / 300 留出场景；2,400 是策略轨迹数 | 条件信息价值、相关转载及模型一致性的受控机制 |
| Round179 发现模拟 | 960 训练 / 240 留出场景；3,600 是最终策略轨迹数 | 候选发现的后续价值、预算与选择性停止 |
| Round174/175/177 旧真实开发比较 | 同一旧区的 290 场重复用于诊断和修正 | 响应模型失配、局部改善与负结果；不能累计为多份独立测试集 |
| Round175 新取得历史时期 | 50 场；参数冻结后下载，但比赛已经发生 | 冻结模型在另一历史时期的表现；不是赛前在线确认，独立赛果金标准未建立 |
| Round179/180 真实赛前运行 | 同三场比赛，多次轨迹 | 实际获取及可回放执行；不能累计为六场，也不能据此可靠学习正文 VoI |

Round180 的八次自主请求与十九次程序来源诊断分列；来源检索工具内部 HTTP 次数未知。三份结构正文、两份含目标实质内容、一条实际提取的球队上下文证据，是不同统计量。词数或结构化段数不能代替相关性、真实性或实际决策收益。

主模拟表的目标是 `log loss + simulated cost`。声明请求费用、资源预约和实际提供方资源分别记录；`money` 为模拟额度时不可写成真实支出。Round175 旧报告的综合目标采用固定 0.5 成本系数，Round177 使用逐折策略系数，因此不能直接跨轮比较旧 `utility_loss`。封版重算表并列纯损失、查询次数、模拟费用、旧报告目标与实际策略权重目标，保留原始文件。

真实历史的负结论限于声明预算和目标。在主预算 0.05／最多两次请求下，上下文残差策略 log loss 为 1.086871，不及不查询的 1.080229；预算 0.03／最多一次请求的上下文策略纯 log loss 为 1.079009，有微小改善，损失加成本为 1.085854，仍高于不查询。不能遗漏这个局部正项，也不能把它表述为稳定或显著的真实策略收益。

同一旧开发留出集上发现历史 URL 原型缺陷、修复请求类表示后再运行，属于开发复验。首次 medoid 失败、中间分派失败及最终结果均保留，不累计样本，不改称预先未见的独立确认。描述性配对 bootstrap 区间只反映该设计的数据，不证明开放新闻泛化或因果收益。

## 影响算法解释的具体假设

1. **有限文本表示。** 返回使用训练期 TF-IDF 和聚类。表示可能把不同事实混在一起，也可能忽略否定、主体和时间；不能把聚类标签解释为真实语义状态。
2. **有序过程。** 响应条件于实际取得的完整有序历史。它不是已经证明查询顺序不变的全局世界模型；缺少历史支持时不回退成独立证据连乘。
3. **中性返回与菜单。** 失败、空结果和索引类别对赛果中性；菜单在给定历史和返回类别后不额外携带赛果信息。这些是建模假设，需要真实数据检验。
4. **未知请求近似。** 未来 URL 的请求类使用冻结训练簇中心规划。已出现的具体 URL 使用实际请求模型重新估值；类层面的支持不保证具体请求同样有支持。规划枚举被禁止用于真实正文更新。
5. **菜单保留。** 规划保持当前未尝试候选并学习新增项，尚未建模候选数量上限造成的删除。子正文核也未条件化于完整菜单身份。
6. **覆盖和成本。** 停止范围限于有支持的有限候选，数值价值条件于估计响应和声明费用。真实工具失败、动态价格、延迟或新来源不能被假定已获相同校准。
7. **选择性采样。** 合成训练可以枚举潜在获取前缀，真实轨迹只记录选过的动作。条件探索概率仅针对当时生成菜单；它不能自动补出未生成候选或未查询内容，也不构成完整的离策略识别。

## 数据准入与当前交付状态

查询前的模型和初态必须已冻结；只用当时取得并实际准入的正文。实际返回时刻被拒绝的正文，不因稍后审计而重新获得训练资格。未来文章、错误主体、未知比赛身份、加时比分以及只有手工声明的赛果，不得作为新 verified batch 的真实训练标签。失败、无关内容和负更新则应保留，不能为改善结果删去。

独立结果强核验由 verified batch/join 入口从原始身份与结果归档实施。底层 `build_open_text_episodes` 接受受信任 supervisor 输入，其字段检查本身不能代替独立原始结果核验。这两个接口的责任不能混淆。

当前可冻结交付：后端入口、两个受控机制、历史负结果、真实赛前归档、复算工具、操作说明与本组材料。仍待研究验证：足量合格的真实正文获取轨迹、独立标签、校准、未参与修复的冻结确认集，以及更广泛候选和既有方法的公平对照。不得为赶交付而把 `aic_research_claim_ready` 或 `open_world_policy_benefit_proven` 改成 true。
