# 00 答辩人手册总览与学习顺序

**面向对象**：一个**完全没有参与过项目开发、不了解项目历史、没有读过项目代码**的人，他要作为 FootballMind 的项目介绍人与正式答辩者。
**使用方式**：按下方顺序读。**不要跳读**——第 01 与 08 两份是所有后续文档的地基。

## 二、推荐学习顺序（两条路径）

### 路径 A：三天速成（推荐）

**第一天（建立全局）**
1. 08 数据与版本索引 —— 只读 §一（两套系统）、§二（数据集总表）、§三（模型登记），先记住"两代系统不能混"和"四个数据集"
2. 01 项目全局脉络 —— 通读，重点记 §2 的 Brentford–Arsenal 案例与 §3.2 的三层职责（**g 估计 / 策略决定 / f 响应**）
3. 07 答辩速查 §9.1 一分钟介绍 —— 试着**脱稿讲一遍**

**第二天（技术深度）**
4. 02 算法指南 —— 重点读 §A（Embedding）、§B（f）、**§C（g，最重要）**、§F（Δ_f 标签）
5. 03 数据与训练 —— 重点读 §五（训 f）、**§六（生成 g 的标签）**、§七（六段划分）、§八（策略评估）
6. 04 实验结果 —— 通读，重点记 E1/E2/E3 的"能支持 / 不能支持"

**第三天（答辩准备）**
7. 05 前人研究 —— 重点记 §1.4（两个足球 Agent 先例）与 §3（两个贡献的边界）
8. 06 评委问答 —— 逐个过一遍"标准回答"；**10 轮连续追问必须演练一次**
9. 07 速查 —— 背十个数字 + 八条不能混淆的事实
10. 09 证据索引 —— 标记出你可能被追问的 5 个数字对应的路径

**第四天（验收，不可跳过）**
11. **做 [10 答辩人验收卷](10-acceptance-test.md)** —— **先只读 §一 作答，不看文档**；答完再对 §二
12. 若判定为"未通过"或"有条件通过"，**回到对应薄弱环节重学，再测一次**。**不要带着未通过状态去答辩**

### 路径 B：只做最紧的两小时

1. 08 §一 + §二（两代系统 + 四个数据集）——**15 分钟**
2. 01 §2（贯穿案例）+ §3.2（三层职责）——**25 分钟**
3. 07 全程 ——**40 分钟**
4. 06 §8.4（实验与创新类 11 个问题）——**40 分钟**

> ⚠️ 路径 B 只能应付一般追问。**如果评委追问数据划分或标签定义，必须走路径 A。**

## 三、学习完成后你应该具备的能力

**必须能脱口而出的（不看稿）**

1. 用一句话说清研究问题（不是"做足球预测"）。
2. 说清 g / 策略 / f 的三层分工，并强调"采用或停止是策略执行的，不是 g 单独完成的"。
3. 说出 Δ_f 的公式与三个要点（必须同一个 f；增益取决于已有状态；赛果不进赛前输入）。
4. 说出十个必背数字及其**单位**。
5. 说出三个必承认（VoI 非首创、按需检索非首创、2026 年已有两篇足球 Agent 先例）。

**必须能应付追问的**

6. 被问"g 会不会排序候选"时，正确区分 `state_ridge`（**不会**，同状态同分）与 `fulltext_*`（**会**，但未证明在完整策略上有效）。
7. 被问"160 场都对了吗"时，立刻纠正为"**复现一致性，不是预测正确率**"。
8. 被问"有没有证明优于市场"时，如实说"**测试集上市场参考更低（1.020413 vs 我们的 1.021563）**"，并补充市场参考的 `prior_time_verified = false`。
9. 被问"为什么效果这么弱"时，能指向 `best_epoch = 1` 与"MLP 训练 6.7e-6 / 测试 2.52e-4，比恒零基线还差"这一组证据。
10. 被问"最失败的一次实验"时，能主动说 Brentford–Arsenal 案例的 Δ_f = **−0.015919**，并说明这正是需要全量策略评估的原因。

**必须能守住的边界**

11. 不说"已证明模型有效"、"已超越市场"、"已实现最优停止"、"概率已校准"、"跨语言能力"、"稳定盈利"。
12. 不把两代系统混着讲；不把 160 场演示当训练集或前瞻测试；不把 4,521 条前缀当比赛数。

## 五、三条使用纪律

1. **数字冲突时以 [08](08-data-dictionary-and-version-map.md) 为准。** 若你在其他文档发现与本手册不一致的数字，**先核对 08，再回报**。
2. **凡本手册未列出的实现细节，不得凭常识补写。** 宁可说"这一点我需要确认"，也不要说一个听起来合理的猜测。
3. **不要为了讲解流畅而省略限定词。** 本手册里所有"但""然而""不能声称"都是**必须说出来的部分**，不是可以省略的铺垫。

## 六、一页速览：答辩当天最需要记住的九句话

1. 我们研究的是**信息获取决策**，不是比分预测。
2. **g 估计，策略决定，f 响应**——采用或停止不是 g 单独完成的。
3. **Δ_f = L_before − L_after，必须是同一个冻结 f。**
4. 赛果**只在训练和结算阶段**使用，**绝不进入赛前输入**。
5. **160/160 是数值复现一致性，不是预测正确率。**
6. 测试集点估计最低，但**配对 95% 区间包含零**。
7. 测试集上**原始市场参考的损失更低**，且 `prior_time_verified = false`。
8. `state_ridge` **按设计不给候选排序**（同状态同分）——它学的是"继续还是停止"。
9. **VoI 不是我们首创；2026 年已有两篇足球 Agent 先例，其中一篇报告四个前沿模型无一超过市场 Brier。**
