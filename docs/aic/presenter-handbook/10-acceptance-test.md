# §二 答案要点与判定标准（考官用，不要提前给答辩人）

## 环节一 判定

**必须说到的**（缺一即不合格）：
- 研究问题是**信息获取决策**：已有初步判断时，新信息不断出现，如何判断**哪条值得采用、采用后带来什么变化、什么时候停止**
- 足球是**实验场景**，不是目的

**加分**：说出场景为什么适配（信息开放但不完整 / 来源参差 / 有时效性 / **结果可事后客观核验**）

**不合格信号**：说成"我们的模型预测更准"；说成"我们做了一个多智能体系统"；把足球说成目标而不是场景

**追问答案**：普通预测器是**静态**的——读一次输入就输出一个概率，不会问"我还缺什么"。本系统是**序贯**的，会产生候选、估值、采用、更新、再决策、停止，并留下可追溯记录。

---

## 环节二 判定

**必须画对/说对的**：

| 项 | 正确答案 |
|---|---|
| f 的输入 | 已采用正文的 **256 维**向量集合 + **16 维**生效元数据 + s0 先验 |
| f 的输出 | 主/平/客三分概率 |
| f 的训练目标 | **历史赛果**（三分类），交叉熵 |
| f 的参数量 | 集合 **26,823**；GRU **67,079** |
| g 的输入 | **1140 维** = 状态 349 + 候选 256 + 绝对差 256 + 逐元素积 256 + 候选元数据 22 + 最大相似度 1 |
| g 的输出 | **一个标量**，估计条件预测增益 |
| g 的训练目标 | **Δ_f**（同一冻结 f 在采用候选前后的损失差） |
| g 的参数量 | 视头而定：state_ridge **350** / fulltext_ridge **1141** / fulltext_mlp **154,369** |
| 选择策略位置 | **在 g 之后、f 之前**（g 给分数 → 策略决定采用或停止 → 采用后才进 f） |

**追问答案**：
- **谁决定采用**：**选择策略**。g 只给分数。正确表述是"**g 估计，策略决定，f 响应**"。
- **谁先训练**：**先 f，后 g**。因为 g 的标签是用冻结的 f 算出来的。
- **换 f 后 g 能否复用**：**不能**。旧版 g 的状态被明确标记为 `not_reused_across_incompatible_f_binding`。

**不合格信号**：
- 说"g 决定要不要读"（分工错）
- 说"g 和 f 可以一起训练"（因果倒置）
- 把 f 的 16 维元数据与 g 的 22 维 `candidate_metadata` 混为一谈

---

## 环节三 判定

**必须覆盖的七个点**：

| # | 要点 | 正确答案 |
|---|---|---|
| 1 | 正文 ID | `document_id = sha256(正文 UTF-8)`，**天然去重** |
| 2 | 语义表示 | 冻结 Qwen3-Embedding-0.6B；原生 **1024** 维 → 取前 **256** 维 → L2；**全文原样、不注入标题、不截断** |
| 3 | 标签生成 | 冻结同一个 f → 算 `L_before` → 把候选向量加入状态 → 重算 `L_after` → `Δ_f = L_before − L_after` |
| 4 | 赛果的位置 | **只用于训练与结算**；schema 显式禁止 `outcome` / `realized_gain` / `candidate_after_probability` 进入 g 的输入 |
| 5 | f 的算量 | **294 场 / 521 篇**（**不是** 1,520 场，更不是 24,911 场） |
| 6 | 划分 | 六段 **294 / 74 / 479 / 160 / 193 / 320**，相加 = **1,520**；**两两比赛交集为 0** |
| 7 | 前缀 | 一场比赛可对应多篇正文与多个前缀；**4,521 条前缀不是 4,521 场比赛** |

**加分**：说出"先对每场全部前缀平均（含 s0），再按比赛等权"，理由是**避免报道多的比赛被过度加权**

**不合格信号**：
- 说"我们用 1,520 场训练文本模型"
- 说"我们把 24,911 场都用了"
- 说"4,521 是比赛数"
- 说不清赛果到底用在哪一步

**追问答案（关键三条）**：
- **为什么采用前后必须用同一个预测器**：否则损失差里混进了"换模型"的效果，**无法归因给这篇正文**。
- **为什么赛果不能进入赛前输入**：因为那**不是预测，是作弊**。有代码级保障：`parameter_updates_during_predict = false`、`forbidden_inputs`、`outcomes_used_in_prediction = false`，且冻结包实测"**prediction 期间 outcomes 读取被拦截、触发 0 次**"。
- **为什么预测增益不等于经济收益**：Δ_f 是 **log loss 的差**（无量纲评分单位），不含成本、不含赔率、不含风险约束。项目的成本单位是换算额度，**不是真实货币**。

---

## 环节四 判定

**四问答案**：

1. **市场参考 → 空证据 f 之间的差异不能算正文增益。** 因为 f 的 s0 本身已经是"**校准后的市场先验**"（`s0 = "calibrated market prior; no text residual"`），两者之间隔着一个 4 参数的校准器，**与新闻无关**。

2. **这一篇的实际增益是负的：Δ_f = −0.015919。** 算法：`Δ_f = log p_after(Y) − log p_before(Y)`，其中 `Y = 客胜`，即 `log(0.665831) − log(0.676515) = −0.015919`。（采用后客胜从 67.65% 降到 66.58%，而实际就是客胜，所以变差。）

3. **能证明**：从正文到 f 的链路是通的；概率会随证据变化；系统能产生并记录采用编号与停止原因。
   **不能证明**：预测质量改善；g 的判断符合人类直觉；策略有效。

4. **因为 g 目前的判断与人的直觉不一致。** 5 条候选中，得分最高的是那篇投票稿（0.014555，刚过阈值 0.01），而那篇"关于轮换的采访"得分**最低（−0.000924）**。**这一点必须如实说，不能换成伤停新闻来美化案例。**

**不合格信号**：把"市场参考 → f"的差异说成正文贡献；把 Δ_f 说成正数；声称案例证明模型有效

---

## 环节五 判定

**四问答案**：

1. **因为 g 的回归误差小 ≠ 策略表现好。** g 只在"该不该采用"这个**决策**上有用，MSE 反映不了阈值选择质量；且用户最终看到的是**预测损失**，不是中间层误差。

2. **两个结果不一致。** 验证集上 state-Ridge **0.963420 > 固定 0.962062 > 随机 0.962063**——**没有占优**；测试集上它 1.021563 是内部策略最低。**这是真实的验证—测试不一致，必须主动说出来。**

3. **因为配对 bootstrap 的 95% 区间跨 0。** 测试集上"新 g − 随机"的差值是 **−0.000886**，区间 **[−0.002299, +0.000438]**，**包含零**。所以只能说"点估计较低"，不能说"稳定优于随机"。（方法：比赛为抽样单元、2,000 次、seed 20261025。）

4. **原始市场参考的身份有限制。** **`prior_time_verified = false`**——报价时点未被验证。所以它是**历史参考**，不是严格同条件的实时赛前先验。而且它在测试集上是 **1.020413**，**比我们所有内部策略都低**。

**加分**：指出 state_ridge 的输入不含候选向量，**在 334 个多候选决策状态中全部候选同分**，所以它学的是"继续还是停止"，**不是"选哪一篇"**；其收益（若存在）可能来自"少读"而非"读对"。

**不合格信号**：说"我们证明了优于随机"；说"市场参考完全可比"；把验证集与测试集结果混为一致

---

## 环节六 判定

**必须说出的三条承认**：
1. VoI 是 **Howard 1966** 提出的；EVSI 的回归估计 **2015 年后**成熟；预算约束下的非短视信息价值 **2005 年**有次模近似；元推理停止判据 **1991 年**就有。
2. 按需检索与"何时继续检索"是 **2023/2025** 年的工作。
3. **2026 年已有两篇论文在足球赛前预测上完整跑了"自主检索 → 概率预测 → 赛后评估"的闭环**，其中 WC2026-Agents 摘要明确写"**四个前沿模型在 92% 场次给出相同首选，无一超过市场 Brier**"。

**可以说出的两个贡献**：
1. **条件预测增益估计在真实小样本文本下的失效边界刻画**（可复核、检索范围内未见同类报告）
2. **四项联合的证据准入契约**（**待验证**，缺消融，因面板仅 5 条观察无法做）

**加一项工程贡献**：可复现的审计闭环（160/160 逐条一致、赛果读取被拦截 0 次）

**必须加的限制**：
- 只能说"**在本人检索范围内未找到同类报告**"，不能断言"全世界没人做过"
- 只测了 7 个头、1 个标签定义、1 个数据规模，**不能外推到"所有信息价值方法"**

**不合格信号**：声称"我们首次提出信息价值驱动的 Agent"；声称"我们发现了一个新现象"；回避 2026 年两篇先例

## 总评

| 判定 | 条件 |
|---|---|
| **通过** | 七个环节全部合格；五道必答卡全对；环节三能不看文档说出"先 f 后 g、标签依赖 f、赛果只用于监督与结算" |
| **有条件通过** | 环节二、三、四合格，但环节五或六需要提示。**需针对薄弱环节重学后再测一次** |
| **未通过** | 环节三或四不合格（说明数据流程或标签定义没掌握），或把"复现一致性"说成"预测正确率"，或声称"已超越市场/已实现最优停止" |

**一条硬标准**：如果答辩人**只能复述讲稿，却解释不清**以下三条中的任意一条，判定为**未通过**：
1. 为什么采用前后必须使用同一个预测器
2. 为什么赛果不能进入赛前输入
3. 为什么预测增益不等于经济收益
