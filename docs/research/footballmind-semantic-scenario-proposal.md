# 单场语义情景与数学 VoI：当前技术路线说明

更新：2026年10月8日。用户在方案提出后要求继续，当前已按本路线实现并完成真实运行。本文件说明算法、证据与限制；任务以[唯一执行计划](footballmind-delivery-plan.md)为准，不再是等待选择的第二份计划。

## 1 从小样本经验路线调整的依据

已有26场英超、62篇赛前正文，时间划分 A15/B5/C6。A 段整场留一比较纯基率和角色字符 TF-IDF softmax 的预声明正则化网格，纯基率胜出：log loss 1.090284，原 lambda=10 为1.090782。降低收缩也没有胜出。冻结所选预测器后，46个 B 段正文增益全零。

输入核查表明正文改变了表示，正文字符占比中位91.5%，没有证实目录淹没错误。这说明当前小样本预测器没有学出有效正文响应，不能证明新闻无价值，也不能用零增益声明信息充分。

负结果及旧模型保留为经验路线对照。当前交付不再等待大规模数据，不继续靠调正则化或人为放大正文制造响应。目标始终是用户给比赛，Agent 自主判断寻找什么、是否获取、如何更新及停止。

## 2 语义模块和数学模块的责任

语义模块利用预训练能力，根据已知比赛与真实内容自主提出未知、搜索 query、有限情景及观察似然。来源正文必须实际取得；先验、情景影响幅度和似然明确为模型假设，不是文章给出的统计概率。

数学模块建立一致联合分布，对未见返回积分预期风险下降，扣除声明成本，选择动作或停止。LLM 协议没有 gain、cost、selected_action 或最终 forecast 字段，不能把语言信心或自报收益直接交给执行器。

当前 provider 使用 CLI 默认请求配置，response_model 未报告。可冻结协议、实际 proposal、参数、原始返回与轨迹用于回放；无法核实服务端权重，没有依据声称它已固定。可请求模型名称也不等于验证了权重版本。

## 3 自主提出信息与动态候选

1. 初态由预配置比赛身份、已有结构化基准 p0、来源入口与固定预算构成，不要求用户指定调查问题。
2. 一次源入口读取作为明确的启动发现开销。语义模型根据当前状态提出0—3条查询及信息需求，不能执行工具或读取隐藏正文。
3. 真实新闻链接与生成查询组成有界可执行菜单，首次最多8项，记录截断与未纳入项。提出 query 不等于执行；数学选择后才请求。
4. read_url 声明一次 HTTP；search_then_read 声明搜索后读取首个允许新闻链接，至多两次。摘要或标题不能回答证据问题。
5. proposal 必须覆盖全部传入候选。实际内容发现新候选时，通过 action extension 新增似然，不改原情景、先验、结果分布或旧动作；自动检查已条件化后验保持。

新增似然条件于当前真实历史。当前实现一步求解、返回后再规划，不把这些参数随意用于未发生反事实分支，也不声称解决一般多步互补获取。

## 4 一致联合模型与精确积分

theta 表示2—6个有限情景，Y 表示胜平负，Z_a 表示 supports/refutes/no_answer：

    q(theta, y, z_a | H) = pi_H(theta) q(y | theta) q(z_a | theta, a, H)

程序验证概率有限、严格正、归一、情景覆盖和动作身份。情景互斥边界、遗漏因素及解释意义仍是可审阅假设，不能由 JSON 校验证明。

通过固定初始先验、共享结果 logit 偏移的联合 I 投影，约束：

    sum_theta pi_initial(theta) q(y | theta) = p0(y)

初态、读后预测与更新来自同一联合对象。这是边际一致性，不是统计校准或对来源可靠率的证明。

对数损失下：

    VoI_q(a | H) = entropy_q(Y | H)
                  - sum_z q(z | H,a) entropy_q(Y | H,z,a)
    net_q(a | H) = VoI_q(a | H) - lambda × declared_request_cost(a)

求解器对三个未见返回分支精确求和，实际观察后用 Bayes 规则更新 pi_H，再估剩余候选。信息价值来自数学积分，不是 LLM 输出的分数。

## 5 真实返回、依赖与稳健性

实际正文通过同页解析、内容角色及时间准入，分类只查看本次取得的正文与固定问题。只有连续引文支持且标记 match_specific 的 supports/refutes 能作为有信息观察。代码证明引文在正文中，不证明来源断言真实或适用性分类正确。

失败、空返回、不回答问题或一般球队背景为 no_answer。每个动作的 no_answer 似然跨情景相同，因此消耗请求但不改变信念。缺乏提及不代表反驳；国家队出勤、旧照片或标题不自动证明后来俱乐部比赛首发、伤停或战术。

同事实、转载与重复来源归同 observation group，每组只尝试一次，防止重复独立累乘。不同组给定完整情景后条件独立仍是假设，残余依赖未建模。

预声明污染强度 [0, 0.25, 0.5]，将似然与不区分情景的边际混合。每个模型独立更新和积分，选择净价值集合下界最高且为正的动作。下界是模型包络，不是统计置信区间，没有覆盖全部遗漏或开放世界。没有正下界仅能解释声明模型和菜单内的保守停止。

主运行 HTTP 成本每次0.001 nats，LLM 时延和 token 单列，尚未计入目标。损失权衡参数不是实际价格，未知费用不记为零。独立零成本演练与敏感性结果不得替换主实验结论。

## 7 提交前保留的最小研究工作

1. 固定实际提案完成有限名义／稳健、成本敏感性与无答案比较。没有共同返回时仅比较模型条件决策，不制造反事实正文或实际收益。
2. 人审真实自动生成的问题、情景边界、影响幅度与观察似然，并核查本次 team_context 引文为何不能回答本场。来源事实、语义假设与最终推断逐项分开。
3. 统一参赛主叙述、主运行、独立机制演练、构造检查和历史负结果，进入10月20—22日人工体验、23—24日修复封版、25日提交。新增时间只用于候选再发现、查询命题绑定和风险分支诊断，不开启联赛扩展、前端或一般数据采集。

本期可成立的主张是：**在明确可检查的语义概率假设下，以一致联合模型的数学 VoI 控制自主信息获取。** 真实概率校准、跨案例平均效果、完整来源依赖和一般多步探索是后续研究，不在此刻伪装为完成。
