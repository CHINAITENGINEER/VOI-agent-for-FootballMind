**一、如何理解项目的算法主线**

任务是：用户输入比赛，系统取得当时可见的初始信息，生成可查候选，估计查询价值，选取信息，收到返回后更新判断，再决定继续、暂缓或停止。胜平负预测提供可量化的下游损失；“主动找什么、何时停”是主要研究对象。

设 H 为已经实际取得的信息，a 为候选查询，o 为实际返回，y 为赛果。系统中有两种不同的价值定义，不能混用：

1. 在一个明确的联合概率模型内，`EVSI = 当前 Bayes 风险 − 对可能返回求期望的后验 Bayes 风险`。对数损失下它等于相应条件互信息，模型内部应非负。但模型可能不符合现实。
2. 对一个固定、可能失配的预测器 f，实际查询收益是 `delta = log f(H+o)[y] − log f(H)[y]`。它可以为负。学习器 g 估计查询前条件下的平均 delta，再减去成本。

因此，“模型算出有价值”“读后概率变化”“实际赛果下损失下降”和“独立样本中平均净收益提升”是四个不同层次。项目已有实验明确展示了它们可能不一致。

核心计算可直接写为以下形式，实际实现还包含支持、时钟和物理预算检查：

```text
当前最优终止风险：R(H) = min_d E[L(d,Y) | H]
一步价值：EVSI(H,a) = R(H) - Σ_o P(o|H,a) R(H+o)
一步净值：N1(H,a) = EVSI(H,a) - λ·cost(a)
有限两步：N2(H,a) = N1(H,a) + Σ_o P(o|H,a) max(0, max_b N1(H+o,b))
经验监督：delta = log f(H+o)[y] - log f(H)[y]
经验选择：a* = argmax_a [g(H,a) - λ·cost(a)]
```

两步式中的 b 只能来自该分支实际允许且剩余预算可负担的动作；动态发现模型还要对新增菜单求期望。某些模型未知时，该式没有自动数值答案。运行顺序为：构造当前可见状态→生成合法候选→计算有支持的净值→执行正值选择或限定探索→保留真实返回与成本→使用同一f更新→重新估值。没有可执行正值动作时，根据支持、菜单完整性、预算和时间分别返回STOP或DEFER，不从未知推导“没有价值”。

**二、已实现的胜平负预测算法**

预测目标是常规时间加补时的主胜、平局、客胜，排除加时和点球。

| 算法 | 已实现方法 | 当前验证范围 |
|---|---|---|
| 联赛频率基线 | 按联赛统计 H/D/A，使用对称 Dirichlet 平滑；默认 alpha=1 | 真实历史重建、真实预测与小样本前瞻结算 |
| 市场去水 | 对同来源、同时间完整 1X2 赔率取倒数并归一化：`p_i=(1/odds_i)/sum(1/odds)` | 真实市场初态与 12 场前瞻结算；早期历史重建缺合格市场报价 |
| Poisson 攻防模型 | 联赛主客进球率、球队进攻/防守参数，岭正则极大似然；支持可选时间衰减；比分分布求和为 H/D/A | 290 场历史重建中概率评分最佳的传统模型 |
| Dixon–Coles | 在 Poisson 攻防模型上拟合低比分相关性修正，处理 0:0、0:1、1:0、1:1 等低比分依赖 | 同一历史重建中接近 Poisson，未证明更优 |
| Elo 与三分类映射 | 平台维护 Elo；研究模型用 Davidson 映射输出三分类，支持拟合主场优势和平局参数 | 同一历史重建中准确率点估计最高，但 log loss 不及 Poisson |
| 多项逻辑回归 | 训练期中位数插补、缺失指示、标准化和正则化三分类；只接受明确赛前字段 | 已训练、保存、加载并评估；该历史实验不及简单模型 |
| 小型决策树 | 固定随机种子、小深度、最小叶子样本、叶子 Laplace 平滑 | 已实际评估；该历史实验表现较差 |

**四、开放文本、动态发现与最新 f/g 路线**

1. **有序正文响应模型。** `TextReturnModel` 用训练期 TF-IDF 和聚类编码请求与正文，学习 `q(z_t|Y,原始p0,a_t,实际有序历史)`。获取前枚举返回，实际返回后用同一冻结条件核更新。失败、空数据、目录等有各自类型，未见来源或历史保留 UNKNOWN。源码：[text_returns.py](<D:/a1-足彩/football_research/acquisition/text_returns.py>)。
2. **发现动作的两步价值。** `DiscoveryReturnModel` 学习“读完当前页面会出现什么请求类”，衡量先搜索或读目录、再读正文的后续价值。未来请求类仅用于内部规划，实际 URL 必须真的被发现后才可执行。源码：[discovery_returns.py](<D:/a1-足彩/football_research/acquisition/discovery_returns.py>)。
3. **正文经验风险校准。** 固定文本预测器，真实或模拟响应在校准侧重放；内部计算有符号损失改善，再按查询前上下文校准模型 EVSI。源码：[text_risk.py](<D:/a1-足彩/football_research/acquisition/text_risk.py>)。
4. **局部历史泛化。** 允许受限制的一次相邻历史交换，权重 `exp(−0.5×交换次数)`；保持同请求的响应次序、重复次数及中性事件次序约束。属于可检验的局部平滑假设，不是“信息顺序无关”的证明。源码：[text_history.py](<D:/a1-足彩/football_research/acquisition/text_history.py>)。
5. **邻域预测器的经验风险校准。** 固定邻域 f，以来源、请求簇、有序历史和支持来源为父组，局部概率/EVSI 分桶收缩。每场等权，保留负更新和未知返回。源码：[neighborhood_text_risk.py](<D:/a1-足彩/football_research/acquisition/neighborhood_text_risk.py>)。
6. **共享可见状态。** 已读正文、已见链接锚文本、时间、原始先验、真实有序查询历史和候选上下文进入同一结构；未读正文不能进入。源码：[visible_state.py](<D:/a1-足彩/football_research/acquisition/visible_state.py>)。
7. **新的上下文预测器 f。** 已实现 `p_f=softmax(log p_market + phi(H)W)`。字符 3—5 gram TF-IDF，上限 512 特征；结合可见来源、正文/标题/链接比例、失败和空返回、近期查询状态、发布时间缺失与年龄。正则系数固定 10，用 L-BFGS-B 拟合；物理比赛等权，再在同场不同前缀内等权。空内容或全部词表外时回到市场先验。完整历史在上游保存，当前模型只使用摘要，不能称为已理解全部顺序和矛盾。源码：[context_predictor.py](<D:/a1-足彩/football_research/acquisition/context_predictor.py>)。
8. **同一冻结 f 的查询收益监督。** 已实现从真实原档重放 before/after、验证模型冻结时钟和独立赛果，产生 `delta=log f(after)[y]−log f(before)[y]`。它是监督数据构建器，**不是已经训练好的新 g**。源码：[context_gain.py](<D:/a1-足彩/football_research/acquisition/context_gain.py>)。
9. **带状态与候选交互的收益估计器 g。** R196新增固定正则20的岭回归，训练期文本表示最多256维，并加入固定128维有符号TensorSketch双线性交互：`g(s,a)=w·[state,candidate]+v·sketch(normalize(state)⊗normalize(candidate))`。这解决纯加性状态项在比较同成本候选时抵消、无法充分改变候选相对排序的问题。输入只含查询前可见文本、标签、来源、工具、概率与声明成本；不含目标未读正文、赛果、比赛ID或具体URL路径。源码：[context_value.py](<D:/a1-足彩/football_research/acquisition/context_value.py>)。这是经验有符号收益回归，不是严格Bayes EVSI或因果估计。

旧正文核与 critic 曾在构造数据上拟合并实验。最新共享上下文 f/g 的训练实现及构造运行也已完成，但截至 R196 真实数据门槛未满足，没有真实冻结 f，没有真实 B 组校准 run，没有训练真实新 g。不能把不同路线中“已有训练代码”“有合成模型”和“真实上线模型”合为一项已完成成果。

**五、Agent 和证据处理已经实现什么**

LLM 调查层实现了问题与假设生成、来源引文、适用范围、正反陈述、冲突、预期返回分支、多候选选择、读取后反馈和再规划。项目后期也有数值模型与确定性候选生成的运行路径；不能把所有真实采集都称作 LLM 自主决定。

候选生成已经支持从实际已读页面发现链接、保留锚文本和 DOM 位置、区分目录与新闻正文，以及按已见正文形成后续查询。news5 正文提取依据页面结构、同页文章元数据和唯一正文容器；它解决抽取问题，不判断新闻是否真实或对比赛有价值。真实失败案例包括选到与目标男子比赛不相关的女足荣誉文章。

执行层有预算、请求前持久化、实际返回归档、时间截止、身份绑定、来源版本、恢复、追加式账本、精确回放、独立结果核验、A/B/C 学习用途登记。`STOP` 与 `DEFER` 有不同原因：有限有支持菜单内无正净收益、支持不足、菜单不完整、预算不足、截止时间、来源失败不能混为“已经掌握足够信息”。

**R1 功能验证。** 真实冻结输入上为 18 场未来比赛生成 54 条预测，保存并重载 14 个模型，独立重训后预测与模型文件逐字节一致。严格历史赛前评分为 0，因为已完赛记录首次被系统观测的时间晚于要求的历史赛前时点。结论是链路可运行与可复现，不是预测效果已建立。来源：[首轮结果](<D:/a1-足彩/docs/research/baselines/results.md>)。

**R2 历史重建。** Understat 英超 2025/26 共 380 场、20 队；7 个扩展时间窗口；共同测试 290 场；24h/1h 两提前量分别建模，共 3480 条测试预测。两提前量输入相同，因此成绩相同，不能算 580 个独立测试比赛。

**十四、现在能确定的结论**

1. **传统预测基线已经实现并实际训练评估。** 在特定历史重建集，Poisson/DC比频率好；没有稳定胜过市场或长期投注收益结论。
2. **有限信息获取机制已跑通。** 条件查询、返回后改选、互补、冗余、无关信息、来源探针与有范围停止有可复算机制证据。
3. **数学正确性无法替代现实估值。** 联合模型一致性可以接近机器精度，同时实际收益为负。更深规划不能自动纠正响应模型失配。
4. **上下文和校准有局部信号，但未建立真实稳定优势。** R6/R10有正点估计或有限区间信号，R7公平比较后变弱；R186/R187效果区间跨零并有负迁移与漏查。
5. **少查不等于更好。** R3/R183展示了少查却损失更大；R179综合目标更好而纯损失稍差，必须一起报告。
6. **真实自主获取已有案例，真实数值VoI效果仍缺。** 真实LLM调查和真实网页执行存在；最新采集主要是有限UNKNOWN探索，R112真实对照未解决目标。
7. **独立支持、内容质量与分期数据是当前实质缺口。** 六场有标签且缺主胜，无法支持现有真实f训练门；冻结f后的B以及更晚C均尚缺。
8. **新颖性主张必须落到具体机制。** Poisson、Elo、VoI、CMI、minimax、TF-IDF、两步规划、多Agent开发、MCP和更多爬虫本身都不是项目已经证明的新理论。现有贡献可表述为可审计、可回放的条件信息获取研究原型与已验证的具体机制，不能声称已证明全网最优搜索或真实足球稳定增益。
