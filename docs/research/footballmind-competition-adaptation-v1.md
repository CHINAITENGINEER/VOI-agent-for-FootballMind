# FootballMind 联赛目录适配 v1

本版本把赛程目录中的联赛名称统一为稳定的中文键，并增加展示分组：欧洲五大联赛、其他欧洲联赛、洲际俱乐部赛事、亚洲、美洲和其他赛事。

已覆盖的显示分类包括：英超、西甲、意甲、德甲、法甲；葡超、荷甲、土超、苏超、比甲、英冠、英甲、英乙、法乙、瑞超、西乙、意乙；欧冠、欧联、欧协联、解放者杯、南美杯、亚冠精英、亚冠二级；中超、中甲、日职、日乙、K 联赛、沙特联、沙甲；巴甲、巴乙、阿甲、墨超、美职联。

这次适配只改变赛程身份的标准化和界面分组。它不会因为一个联赛能显示在赛程页，就自动授予 f/g 分析权限。真正启动一场分析仍然必须同时满足：

1. 来源比赛身份完整且可复现；
2. 赛前仍未开球并且有新鲜的完整 1X2 先验；
3. 该来源的初始化器和身份绑定能够处理这场比赛；
4. 正文来源、赛果来源和 f/g 运行合同均已配置。

目前英超有独立官方赛程核验路径。其他联赛（包括中超和中甲）在本版本中完成了赛程分类和来源显示，但没有被冒充为已经完成跨源身份核验、f 校准或 empirical g 训练。没有完整市场先验的 ESPN 赛程会继续显示为可查看但不可启动。

验证：`tests/demo/test_live_coverage.py` 与 `tests/demo/test_daily_fixtures.py` 共 42 项通过，`demo/static/live.js` 的 Node 语法检查通过。
