# E 盘正文 f 第一轮训练（2026-10-20）

产物在 `E:/FootballMind/experiments/text-f-v1`；原始数据在
`E:/FootballMind/corpus-v1`。本轮真实训练了新的研究候选 f，没有替换在线 f/g。

## 问题与方法

验证已取得的正文向量能否在历史状态概率之外增加预测能力。基线是 11 维赛前
滞后特征的多分类逻辑回归；它仅拟合 2019-07-01 之前的 1,900 场英超，确保没有
用正文面板中任何目标比赛的结果拟合基础模型。其正则化由更早的时间验证选择。
这保证目标隔离，但旧基线不代表当前最强市场模型。

文本面板按时间分为 74 场训练、22 场验证、46 场测试，共 219 篇不同候选正文。
训练截至 2025-07-01，验证截至 2026-01-01，此后是测试。排除比赛当天顺序不明
的材料、明确在比赛当天或之后修改的材料和青年/女队材料；跨分组共享正文簇全侧清除。
范围过滤补上了 U18s/U21s 复数形式。原始正文、旧关联产物不被覆盖。

元数据、标题和正文三个分支都使用同一基线、同一比赛划分、同一训练子集规则。
标题/正文分支按主客队分别平均 384 维文章向量，再与状态/元数据输入 16 隐单元
tanh 残差网络；每个文本分支 12,659 个可训练参数。固定句向量编码器没有微调。
公式为 `softmax(log(p_base) + residual(read_evidence, state))`；空证据直接返回
原始 `p_base`，保持逐位相等。文章数量/来源/年龄控制分支有 371 个参数。

训练使用每场文章的顺序前缀和单篇子集，去重后每场总权重相同，不把同场多篇当作
独立比赛。每个分支只用验证集选择 0.001、0.01、0.1、1.0 中的正则化，测试集
不参与调参。protocol.json 和 panel.jsonl 在加载目标标签前写入。

## 实际结果

平均 log loss，越小越好：

| 模型 | 验证 22 场 | 测试 46 场 |
|---|---:|---:|
| 只用历史状态 | 0.735660 | 1.006494 |
| 历史状态 + 文章元数据 | 0.752111 | 0.998302 |
| 历史状态 + 标题向量 | 0.787518 | 0.962408 |
| 历史状态 + 正文向量 | 0.761298 | 0.975488 |

正文分支测试损失减少 0.031006，但验证损失增加 0.025638。测试集标题分支优于
正文分支。正文相对基线的逐比赛 bootstrap 损失减少量区间约为 [-0.008027, 0.074235]，
含零，且队伍/时间相关性让这一区间只能作描述性参考。按事先规则，本轮保留基线，
不能看过测试结果后反过来宣布正文模型胜出。强正则化被验证集选中，弱正则化的
验证损失很差，说明当前小面板承受不了自由度快速扩张。

在固定元数据而打乱测试正文向量的推理扰动下，正文模型 log loss 为 1.009224。
这说明输入正文向量会影响输出，但不是经过重新训练的随机对照，更不是因果证据。

## f 消费与 g 标签边界

固定正文候选 f 已生成测试集中 96 条顺序读取转移：47 条损失减少、49 条损失增加，
没有数值零收益转移；逐条记录读取前状态、标题、已读文章 ID、after 概率和同一 f 摘要。
这些是留出的评估样本，保存在 `test-fixed-f-transitions.jsonl`，不送回 g 训练。
负收益本身不是排除理由；隔离原因是其属于测试集。

`FrozenCorpusTextPredictor` 可以从保存的模型重载，显式传入已读文章 ID 后预测，
不读取赛果、不联网、不训练。对 68 场验证/测试预测独立重载复算，最大浮点误差
约 1.11e-16。无正文的预测保持基线原值。未来生成 g 标签应使用训练区间内的
时间交叉拟合或单独 B 面板，不能把本次测试结果当训练数据。

仍有两个重要研究限制：新闻与比赛的匹配是球队/日期候选关系，未全部逐篇确认直接
指向本场；正文是当前抓取版本，历史发布时间是来源声明，无法冒称当年的前瞻观测。
本轮对整个旧 f 系统没有“已全面修复”主张，也没有真实未来比赛上的性能主张。

## 复现

新实验目录必须不存在，避免覆盖旧实验：

```powershell
$env:PYTHONPATH='.'
$env:TEMP='E:/FootballMind/corpus-v1/tmp'
$env:TMP=$env:TEMP
python tools/train_e_drive_text_f.py --root E:/FootballMind/corpus-v1 --output E:/FootballMind/experiments/text-f-v1-reproduce
python -m pytest -q tests/acquisition/test_corpus_text_f.py tests/acquisition/test_e_drive_corpus.py --basetemp E:/FootballMind/test-tmp/text-f-check
```

下一步重点是训练区间的滚动交叉拟合和多球队/多赛季的正文面板补强；不依据测试结果
继续寻找更好参数，也不把候选标题、正文打乱对照的结果夸大成 g 的选择能力。
