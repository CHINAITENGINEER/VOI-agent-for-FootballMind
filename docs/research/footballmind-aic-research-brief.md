# FootballMind：开放信息环境下基于状态条件信息价值的自主获取 Agent

2026年10月8日研究说明草稿；以已实现版本为依据。提交截止已延至10月25日，具体提交格式须与赛事正式模板对应。本说明不把待做能力写成既有结果。

**10月9日最新实现：预训练语义情景＋数学VoI。** 用户只提供比赛。Agent提出关键未知与可执行查询，给出明确标为模型假设的有限情景、先验、条件赛果与观察似然；数学模块将情景边缘与现有结构化基线对齐，默认计算一步期望风险下降，也可在冻结可见菜单内显式启用一个后续动作的两步 Bellman 前视，扣除请求成本，并在查询前固定的似然污染模型集合上比较净价值下包络。实际正文引用用于分类观察与Bayes更新；失败、无答案、未确认本场适用性的背景不能强行更新概率。新候选可以从返回链接扩展，既有情景及已接纳后验不被改写。

真实主运行live-01在0.001 nats/HTTP下，8个候选均未超过成本，真实1HTTP/2LLM后停止。另存零损失成本机制诊断mechanism-01，真实6HTTP/6LLM、3篇正文、5次no_answer、6周期，所有污染模型后验不变并因预算停止。两者冻结数学回放通过。不同信息返回能改变下一动作的证据目前来自明确构造的机制测试；真实主案尚无可采纳的本场正文来证明这一分支，也未证明预测改善或优于固定/随机策略。不能把零成本执行数量包装为VoI策略成功。

研究贡献候选因此是“在明确语义假设下，将开放候选生成、预期风险积分、真实观察更新与有界停止连接起来”，不能宣称已经从少量足球新闻训练出可靠的收益模型。概率桥没有实证校准；模型集合下界不是置信区间；远端预训练模型权重身份未验证，冻结的是实际提案和执行产物。下一步审查情景合理性、来源适用性和最小对照；无须等待更多比赛结果才能审阅研究原型。具体当前主线见 [执行计划](footballmind-delivery-plan.md)，实现入口见 [运行说明](footballmind-single-case-runbook.md)。

下文是P1–P5经验学习路线的原始研究记录，保留负结果与撤回说明，其“当前结论”只对该经验路线成立。

## 历史正文机制检查

为检查真实正文进入系统后的证据边界，按预先记录的元数据规则，从 C 段选择最早具备两篇官方赛前正文的 Leeds–Fulham。选择没有读取正文、赛果、标签或 VoI；面板排除目标比分和结果，保留来源发布时间、后来的归档捕获时间及 raw 哈希。正常成本的重建回放在目录后停止，说明查询成本仍由数学模块控制；将成本设为零的独立机制回放才读取两篇正文。

两篇正文都被真实工具返回并送入语义分类器，但返回均为 `no_answer`：其中一篇引用了本场正文，却只足以说明一名球员处于康复/训练状态，不能证明关键球员缺阵或本场实际出场限制；另一篇说明球员可供选择，但没有足够证据确认具体战术变化。三次观察均没有改变任何污染模型下的情景后验。该结果展示了来源事实、语义适用性判断和概率更新之间的边界，不能证明这些报道“没有价值”，也不能证明预测效果。

同一返回面板的策略对照保存于 `var/submission/p7-historical-semantic/mechanism-02/controls.json`。自适应 VoI、固定顺序、冻结后验消融与零采集共享冻结模型和实际观察；固定顺序所需的未返回动作按 `missing_panel_return` 标记，不生成反事实结果。对照只研究选择与更新机制，不使用比赛结果，不计算实测收益。该历史面板是后来抓取的历史出版物重建，不是当时网络环境的独立快照。

追加的 `mechanism-03` 在相同历史面板上把零成本预算扩展到6次请求，出现了一条真正可检查的条件更新：搜索无答案后，Agent选择读取第一篇正文；分类器引用 Daniel James 康复和 Bornauw 回归训练的连续原文，将该观察判为 `supports + match_specific`。第二篇正文虽提到可选择球员，但不能证明战术改变，保持 `no_answer`。因此保存的5个观察中有1个支持、4个无答案，名义分布按冻结模型从53.4884% / 30.2326% / 16.2791%变为50.7306% / 31.0413% / 18.2281%。这证明了“实际正文—语义适用性—同一联合模型后验”的代码路径真实运行；其中支持判断和情景概率仍是未经校准的语义模型假设，历史正文也不是当时实时快照，不能把概率变化称作赛果预测改善。机制03的自适应、固定顺序、冻结后验和零采集对照见其 `controls.json`。

人工审阅还必须区分“存在本场健康信息”和“已经确认主队利空/利好”：两条引文没有独立证明关键球员一定缺阵、影响方向或影响幅度。当前 `supports` 只代表冻结语义模型接受该正文作为本场健康状态证据；这项方向性压缩已记录在 `mechanism-03/audit.json`，后续应拆成原子方向标签或区间似然。

新增的 `football_agent/directional_evidence.py` 是独立、可选的方向性证据扩展。它在保留旧 `supports/refutes/no_answer` 的同时，要求方向标签、主体、方向依据和逐字引文同时成立；“正在康复/训练/可能出场”等只有状态没有影响方向的正文会被记录为 `unknown + availability_only`。扩展默认不进入当前数值求解器，只有未来完成方向性似然校准并升级模型版本后，才允许影响后验或 VoI。

**当前结论：工程循环可复现；核心“根据新增信息有效改变下一次信息选择”的真实学习能力尚未通过验收。** 本次复核撤回此前关于live-02正文入模及条件收益机制已通过的过强表述。可计算、可回放、参数中有交互项，都不能替代选择能力实验。

最新A-only预测器选模进一步确认：在同一15场/255状态上，纯基率的整场留一log loss为1.090284，原lambda10为1.090782，预声明网格均未胜。重建同一选定f后的46个B正文增益全0。该实验仅证明当前表示与监督没有选出可用正文响应，不证明外部信息无价值。Agent已将这类查询保持UNKNOWN。下文v4与相对选择实验保留为开发记录，不能据此宣称核心学习已完成。新的 [语义情景路线提案](footballmind-semantic-scenario-proposal.md) 尚待用户决定，不写成已落地能力。

## 科学问题

面对尚未完整发现、质量和适用性不一致的信息，系统如何依据当前已知状态决定下一次获取、评估返回对当前预测器的作用，并在收益不足、价值未知或资源受限时结束？足球是本期单场验证环境。用户只指定比赛，不手工指定伤停、天气、战术的优先级。

本期可检验的假设是：已读信息会影响下一条信息的边际价值；因此以固定主题排序或无差别探索作为查询策略，不能充分表达信息之间的条件关系。项目研究的是状态条件化的信息获取，不以提高单项胜平负分数作为唯一目标。

## 已实现的方法

公开工具返回原始内容；解析器提取正文、标题、来源和时钟。Agent只能消费已读正文与已观察到的候选标题。目录入口与工具权限可以预配置，页面中的文章、预期收益和行动顺序不能预先写好。

    比赛身份与来源入口
      → 读取目录/搜索，形成当前候选
      → 角色文本状态 H 与候选 a
      → 固定预测器 f(H)；条件收益估计器 g(H,a)
      → 净收益比较或有限未知探索
      → 实际返回、更新 H、重新估值
      → 有理由的结束与可复现报告

f 为角色分块字符TF-IDF与正则化softmax。g 的候选族包括状态、候选及二者固定交互表示上的ridge与常数基线。把较早的A段用于拟合f并冻结，在之后的B段使用真实正文与赛果重算标签：

\[
\Delta(H,a,o,y)=\log f_y(H\oplus o)-\log f_y(H),\qquad
g(H,a)\approx\mathbb E[\Delta\mid H,a].
\]

策略比较 \(g(H,a)-\lambda^\top c(a)\)。已有目录标题先进入H，正文读取后不再把标题作为新增证据计一次收益。每次返回后仍使用同一个f计算当前概率，并重新估计剩余候选。

v4只在B内按整场留一选模，词表与IDF也由每折训练侧拟合；使用预声明正则化网格并包含常数基线。结果常数胜出，真实部署均值为−0.0002657493，不区分候选与状态。它保留作停止基线，不能称为条件学习已经成功。导航/条款/类别等UI链接已通过训推共用投影排除；不按人为足球主题重要性过滤新闻。

这是同一固定预测器的经验有符号风险改善估计，可为负；它不是精确Bayes EVSI，也不是长期Bellman Q。搜索与目录发现目前没有训练好的后续收益模型，进入独立有限探索额度，不能把探索称为计算出的正信息价值。

严格模式要求完整角色组合匹配。研究泛化模式把已见状态角色组合的精确匹配改为外推诊断，保持候选角色、来源/工具、先验域、可见信息标志及最少两个独立邻居、余弦至少0.2等要求。未经完整局部支持的数值标注为未校准外推。原严格模型和归档保留，模式差异可以对照。

## 本期研究贡献的适当表述

1. 将动态发现的真实内容、读取前条件收益估计、读取后同一预测器更新接成实际运行循环，并保留未知与失败。
2. 用具有源绑定的真实历史正文构造可见标题/已读正文状态，检验“当前已知内容与候选的交互”是否可学习，不人为给足球主题赋价值；目前条件排序核心检查仍未通过。
3. 将绝对收益/停止与同状态相对候选选择分开验证，包含常数与零排序基线，避免支持门、微小数值变化或动作变化被误认成学习收益。

不能把VoI概念、工具协议、多个Agent名称或调用次数当作原创算法成果。本期能够提交的是上述问题设定、实现、机制证据及边界；论文级效果、理论保证和跨领域有效性尚未证明。

## 实际数据及实验

使用26场独立英超比赛、62篇真实官方赛前正文、112条目录标题；按时间分为A15/B5/C6。同一比赛多个状态总训练权重为1。历史来源本次抓取，按明确发表时间重建可用性；保留实际capture时点，不声称拥有当年的网页快照，后期修订风险未排除。

实际训练产生255个A状态和46个B状态—动作标签，其中20正、26负。C保留检查含120个增量，严格模式80可估、40未知。旧v3的24组条件数值变化幅度很小，支持范围内的查/停判断与常数完全一致；不能用该数字宣称已学会条件选择。B只有2主胜、3平、0客胜，同状态候选比较来自4个独立比赛、6个不同文章对。正文会改变表示，但f仍主要围绕训练基率小幅变化。

C按独立比赛等权的平均实际增量为−0.000305443。这是返回机制诊断，不是部署策略收益，也没有证明总体预测提升。C结果及主案例已用于开发诊断，不能包装成完全未接触的最终确认试验。

## 主案例与对照

当前 Arsenal–Leeds实际赛前开发运行为 `live-03`：3次HTTP，目录成功、图集成功、搜索失败。图集只有1段真实导语被v7绑定并接纳，4条图片图注不作为正文；这一导语不能证明本场伤停、首发或轮换。终态模型输入含1段导语与72个不同标题，19个链接标签被排除。真实来源返回后重新计算f和候选值。

所有实际已选动作均为探索，本案例没有发生正VoI驱动的读取。21个可估候选使用同一负常数收益，结束为defer、未知探索额度耗尽；总预算未用完，不能声称信息充分、节省21次请求或学会了条件选择。

支持规则对照固定公共状态、同一f/g、成本与种子，仍可影响有限探索的菜单；这只是支持门的作用。旧live-02的“正文更新”主张已撤回：其正文入模数为0，变化来自链接/状态。旧原档及修正报告分开保留，不改写历史轨迹。

live-03与旧live-02都完成真实原档重投影和精确回放，各4周期、3返回，0网络。模型/标题投影/策略30项、报告32项、解析135项针对性回归通过。测试仅证明实现行为，不证明科学假设成立。

## 针对创新点的相对选择实验

对同一比赛、同一可见状态H中的共同可选候选，使用同一个冻结f定义：

    d(H,a,b) = delta(H,a) - delta(H,b)
    r(H,a) = s(H,a) - mean_b s(H,b)

共同的查询前log概率在差分中消除。菜单特征和目标同时中心化，按比赛/菜单/候选等权，B整场留一选择原岭网格或零排序基线。B只有4场、10个菜单，选中岭强度0.01，验证中心化MSE为4.4122e-8，零基线为4.9652e-8。模型只在离线诊断中运行，不替换live绝对停止头。

C六场、30个菜单的配对正确率为0.60317，对照0.5；最优候选命中0.57143，对照0.48413；均场相对regret为6.3829e-5，对照1.4943e-4。但中心化MSE略差（3.4672e-8，对照3.4340e-8），收益差MSE也略差。C已被检查，不能作为独立确认试验，这些小样本数值不构成普遍优势证明。

最接近项目核心的检查尚缺有力证据：同一发现菜单、共同未读候选、改变已读正文的12个可比较关系中，固定f的事后收益排序反转2次，模型预测反转为0。这些事后收益使用真实赛果，不等于读前期望收益；不能据此要求每个反转都被策略复现，更不能按它们调参制造换序。当前相对选择目标出现有限信号，仍不能宣称收到新信息后调整查询排序的有效性已获验证。

全部产物在 `var/submission/p4-review/conditional-choice/`。相对分数为正不能推导绝对价值为正；所有候选均有害时仍会有相对第一名，所以绝对停止头必须独立保留。

## 答辩展示顺序

1. 输入已配置主案例，说明比赛是任务输入，问题及查询主题由系统推进。
2. 展示真实目录返回后出现的候选与读取前数值，明确外推标记和UNKNOWN。

4. 展示网页成功、导语抽取、实际入模的区别，读取后的预测与下一轮估值，以及结束原因。
5. 展示同状态相对选择实验和未捕捉排序反转的失败例；零网络原档回放验证运行过程。
6. 说明核心条件选择验收尚未通过，不能将本草稿直接描述为完成版；只展示已有方法、实际证据与限制。

## 当前局限与优先改进

训练g只有5个独立比赛，真正候选比较只有4场；当前支持门仅有限邻近比赛，绝对头又选择常数，不能称为可靠条件估计。文本表示较粗，未解决完整的球员指代、战术、来源冲突及因果效果理解。当前只做一步经验收益比较，未学到搜索或目录发现的延续价值。

下一步优先分析两个事后收益反转样例，区分固定f的正文信号、随机赛果与状态交互能否表达候选边际变化；任何改进都须用同菜单、同预算、独立比赛检验，保留常数/零排序对照，不能针对样例强迫换序。不能通过更多界面或审计把研究缺口改称完成。运行命令与证据路径见 [单场运行说明](footballmind-single-case-runbook.md)。
