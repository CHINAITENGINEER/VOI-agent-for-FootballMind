# Round191：正文发现、导航隔离与真实失败轨迹

本项围绕“用户提供比赛，Agent 自主获取下一条信息”修复信息入口。
查询内容没有改成用户问题或人工指定的伤停、天气清单。
信息可读取、属于本场、具有正信息价值，是三个分别核验的问题。

## 已执行的真实运行

在第一次请求前固定四次请求、seed=191、无自动重试，复用仍处于一小时观察窗口内
的原始市场初态。用途事先登记为原比赛的 f_train，同一物理比赛不增加独立样本。
没有把另存研究首页中的十篇文章预先放入 Actor，也没有给文章指定价值或优先级。

实际请求顺序是：

1. 官方比赛页：HTTP200，未知正文角色；不产生导航证据或追问。
2. 赛前搜索：失败，原始回执和实际请求计数保留。
3. 官方首页：HTTP200，作为 index 保留真实链接，不形成正文断言。
4. 自主选取首页刚返回的 Melissa Tancredi 女足荣誉文章：HTTP200，但当时投影为 NO_DATA。

该次运行采用 news projection v2、evidence v4、candidate v5。四次请求后物理预算
耗尽，概率不变，完整回放通过。选择仍是有限预算下的 UNKNOWN 探索，不是已校准
正 VoI；停止没有信息充分性证书。本项没有为了更换失败结果再次运行。

## 已修复的导航污染

原 evidence v3 在 structured_news.role 为 unknown 时回落全文扫描，导致导航文本
生成追问。显式 v4 要求可核验正文片段，无正文标记、unknown、index 均不做全文回退。
JSON-LD 独立标题前缀与 HTML 标题不能作为正文断言；引用仍保留原文位置。
文档和真实链接不删除，允许下一步通过它们发现真正正文。

旧加拿大未知页离线对照中，导航证据与追问从 1 条降为 0，63 个原链接不变。
旧克罗地亚 liveblog 仍保留 15 个目标范围引用与 15 项追查候选；这些不是独立事实
计数，也不意味着查询具有正收益。旧轨迹按旧版本继续精确回放。

候选 v5 允许从已准入、已登记的官方同站页面实际观察到的新闻链接扩展菜单。
失败、相似假域与导航根目录不能伪装成正文候选。来源身份不会自动赋予信息价值。

## 同轮发现的正文投影缺口

最后一条 NO_DATA 并非远端无正文。原始响应有 124276 字节，包含真实文章；
JSON-LD 为 NewsArticle，但未提供 articleBody。旧解析器把“识别到文章元数据”
当作禁止 HTML 正文回退的依据，清空了本来可读的内容。

本轮追加显式 news projection v3、evidence v5 与 candidate v6，解决这个结构缺口，
保留已运行的 v2/v4/v5 配置、全部回执和原始结果。新版本仅从绑定同一页面的元数据
和可确定的正文 DOM 提取段落，记录来源、段落位置、发布时间及精确文本偏移。
标题、导航、页脚、侧栏不能混入正文；错误或未来时间、歧义正文不能绕过旧排除。

新 HTML 正文进入 evidence v5 时，仍需单独核对本场身份。若首个合格正文明确是
非目标组别、且没有同时绑定目标组别，则文章主体保留为未绑定本场的引用，不能
因为后续传记段落只写 Canada 就制造男子比赛的追问。混合组别不作武断整篇排除。
这是实体适用范围处理，不是题材价值白名单。

追加验证只使用已经获得的原始字节，不能改写原 Actor 的 NO_DATA，也不计为新的
实际查询、有效信息收益、独立比赛或监督样本。运行时源码副本在 source-at-live
保存，新增版本与原执行版本的配置分别记录。

真实派生结果为7段、1703字符，原采集时刻UTC19:45:10.034377，派生可用时刻
UTC20:04:42.164528。12条引用均保留为未绑定本场资料，本场证据与追问均为0。
最终1174项相关回归全部通过；当前代码的真实轨迹精确回放、原始数据重建以及
派生正文重投影均再次禁网通过。各子任务测试已包含在总数内，不重复相加。

新采集调用显式指定 `news_projection_version=3`、
`evidence_version="match-evidence-extraction-v5"`、`candidate_discovery_version=6`。
CLI 对应 `--news-projection-version 3 --evidence-version match-evidence-extraction-v5
--candidate-discovery-version 6`。省略版本参数的既有行为保持，不偷偷升级旧配置。

## 当前研究边界

累计仍是 7 场独立比赛，实际运行 11 次、响应 32 次；独立有赛果比赛 1 场，
合格监督响应 2 条。当前训练支持不足，未生成真实预测器或 critic。
本轮没有等待或轮询尚未到期的五场结果；加拿大常规时间结算规则继续未知。

结构正确的正文依然可能与目标比赛无关，甚至内容本身错误。当前随机探索会选择
女足荣誉新闻，正是信息相关性与价值尚未学会的真实失败案例。下一阶段应使用真实
来源返回、身份范围、可获取性及独立赛果，训练并验证查询收益；不能将“获取更多”
或“解析成功”充当决策改进。
