# Round184：真实赛前采集与有限候选响应面板

完成时间：2026-10-06。原十轮工程收敛已在 Round182 结束，本项是其后单独授权的真实信息获取研究任务，不重置原轮次预算。

## 为什么做这一项

项目要回答的是 Agent 在当前证据下应查询什么、是否值得查询、何时停止。上一项已有有符号风险改善学习接口，但缺少真实监督，合成开发复验未证明策略优势。继续调整旧分数不能补齐这个缺口。

本项补的是可追溯的真实响应覆盖。原日志已有实际菜单、选择概率和已选返回；未选择请求的返回一般未知。新增有限面板先固定候选，再单独采集响应，让未来比较能在明确、相同的有限信息集合中逐步读取。它不重建整个开放互联网，不是历史完整反事实，也不是一个新的学习算法。

## 实现与实际结果

`information_panel.py` 提供 freeze / seal / load / reveal。只接受独立身份核验过的真实运行；绑定原周期、已读历史、预测和截止时间。从最后实际周期的原菜单按原顺序选择前两个可执行、整次运行未读的请求。研究正文不回填原 Agent 状态；全部实际请求和失败独立记账。面板时点在实际返回之后、原截止之前。

来源能力增加显式可选的 verified profile v2 / candidate generator v3，支持爱沙尼亚、斯洛伐克已观察官方通用入口的本地语言链接。旧默认和已归档 v1/v2 回放不变。文章地址必须出现在已读取入口的实际 links 中，没有人工选择某篇伤停或战术文章。

五场母集在正文采集之前固定；普通胜平负市场报价、官方赛事身份均从原始响应核验。两场是旧比赛的新轨迹，三场新增，与原三场的独立比赛并集为六。

实际 Agent 请求 16/20 次上限，研究请求 2/10 次上限。研究两页均 HTTP200，有 3,679 / 4,862 字符的现有通用文本投影。完整两候选响应面板为 1/5；现有解析器认可的多正文面板为 0/5。四场零候选面板也保留，未换 seed、重选周期或按成功筛掉案例。

独立赛果标签为 0，新合格数值 VoI 监督为 0，真实效益完成标志仍 false。真实 Agent 仍使用 UNKNOWN VoI 的有限均匀探索，不能把本轮请求称为已学会信息价值后的最优选择。

## 已定位的真实瓶颈

1. 8 次 Agent 请求连接失败。5 次成功搜索共返回 50 条 RSS，但全部不在既定来源范围，抽查为登录、小游戏、百科/旅游等不对题结果。不能通过放宽来源范围把它们冒充有效信息。
2. 爱沙尼亚两页有稳定单一正文 DOM：`div.news-detail > div.body.def`，但没有 JSON-LD 或 `<article>`。旧结构解析保留 unknown，不能将这个状态解释为“页面没有内容”或“信息价值为零”。后续可从已归档原始字节增加显式版本的重解析，无须再次联网；不得覆写本轮冻结投影。
3. 正文使用 `Eesti / Island / Islandi`，旧中文/英文实体别名与日期语法不覆盖本地语言。目标关联未识别也不证明无关。比赛级关联与单队背景应分开，单队消息不能因为没有对手名字被人工排除。
4. 两页来源日期无时区和修改时间，不能捏造 UTC 发布时间。实际观察时间 15:28:39/40 UTC 早于 18:45 UTC 开赛，可以证明此时原文已获取。来源声明的时间与实际获取时间须区分。

Scotland 官方比赛页返回的段落为通用转播/宣传内容，没有目标队伍正文；原关联排除有依据。Croatia 实际产生两条目标证据及两条后续查询。这些差异保留，不按“官方页面”一概认定有用。

## 修复与实验边界

真实首次接入发现 runtime 的终止周期没有普通请求周期的 public_digest。原失败报告保留；修复后从已绑定的原终态字节计算摘要，未重跑任何 Agent 请求。全部五份面板设计与 amendment 先于两次研究请求保存，原 Agent 160 个文件不变。

独立审查修复三个实验漏洞：未读正文的重复标记泄漏；隐藏失败重试造成成本少计；返回对象共享引用导致调用方改写内部历史。现在重复关系只根据已读内容公开，同 panel 的全部原始请求必须入账，公开返回深拷贝。

角色、覆盖与信息价值分离：失败、NO_DATA、目录都是实际响应；没有采到不能填成 NO_DATA；单队背景和未绑定内容保持原样。两份不同正文不证明事实独立。面板保留已有历史，不能把历史读取成本清零或将研究响应倒填至原决策时间。

该批最多作为后续正文预测器 f 的训练候选；风险校准数据需在真实 f 冻结后取得，并与训练比赛隔离。不能把面板模拟顺序送入真实执行前缀导出器冒充在线监督。

- 大范围回归：4,022 passed。该运行在终态兼容最后修复前启动；最终修改另经关键集成回归 38 passed，二者有重叠，不相加。
- 3 份旧运行及 5 份新运行、24 次原始返回，禁止网络后逐字回放通过。
- 独立面板验收 424 项检查，绑定 206 个输入 SHA；5 份面板重新投影、任一响应先读的信息隔离与成本守恒通过。
- Round182 发布包 SHA 与默认部署配置不变；未训练模型、未重算旧 D 追分。
- 实际网络：本轮市场/身份准备 10 次、Agent 16 次、研究响应 2 次、历史快照可行性 6 次，共 34 次 HTTP；来源发现另 7 个搜索查询，不混算为 HTTP。模型内 `.01` 为模拟查询成本，不是实际货币账单。
- 历史快照有界探测取得 0 份合格赛前原文后停止；这不证明全网不存在快照。

## 后续最高收益工作

先用已归档真实页面做明确版本的正文/本地语言关联改进，保留未知与失败；赛后独立核验结果，再导出合格语料。随后冻结真实正文预测器，在之后新比赛上获取信息价值校准记录，最终做相同预测器、候选和预算下的独立比较。当前六场远不足以支持真实 VoI 优势结论。

本轮没有部署后台等待任务。比赛尚未结束时不循环轮询，也没有请求用户手工选择信息主题。
