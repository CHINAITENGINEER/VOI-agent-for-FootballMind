# Round190：真实训练入口与一个新的独立采集场次

本项把原始响应到冻结正文预测器的训练入口接通，并取得一场具有新鲜初态、
独立官方身份的新比赛，完成预登记后的实际 Agent 获取和精确回放。
用户仍只提供比赛；查询由现有策略与预算机制选择。

## 真实训练入口

新增 `football_research.data_adapters.prospective_training`，复用原有 f，不改变数学模型、
支持阈值或旧确认集。输入是原始 run 目录、已登记训练清单和独立赛果归档，不能直接
把任意 records JSON 标为真实训练数据。

入口重新核验原始身份、报价、运行摘要、真实三时钟、完整有序响应及独立赛果。
同一官方比赛的不同 provider ID、重复运行和正文版本只占一个独立样本；训练副本
映射到清单中已有的代表 ID，原始数据不变，导出模型仍可接到 Round189 后续校准。
已用于校准或确认的运行不能改作预测器训练。

审查发现旧桥在前序 receipt 无法读取时，可能将后续响应按缩短的历史处理。
本入口核对真实选中请求步骤与重建 episodes 的完整对应，缺步时完整排除该运行，
同时保存全部原始诊断。中性返回、失败和未知的处理依据已有协议，不只保留好看的正文。

固定使用既有 `min_matches=12`、`min_class_matches=1` 等参数。至少 12 个独立合格
比赛并覆盖主胜、平局、客胜，只是可拟合的必要条件；不意味着未来每个来源、查询、
概率状态与历史都有条件支持，也不证明获取信息能降低实际风险。
不足时仅输出 `not_ready`，不创建模型；满足条件后调用既有 v1 或显式邻域 v2，
保存并重新加载核对完整 payload，仍保留 `production_ready=false`。

```powershell
python -m football_research.data_adapters.prospective_training fit `
  --run ORIGINAL_RUN_FOLDER --previous-plan REGISTERED_TRAINING_INVENTORY.json `
  --result-archive ORIGINAL_RESULT_ARCHIVE --output NEW_TRAINING_DIRECTORY
```

北京时间 2026-10-07 03:17:52 已对真实旧 9 个 run 执行此入口：登记身份 6 场，
合格监督只有 1 场、2 条响应，类别为主胜 0／平局 1／客胜 0。因此 `not_ready`、
`model=null`、未拟合、无冻结模型文件。当前仍没有可以投入真实校准的 f。

## 新比赛的数据路径

上一项的销售日列表返回空，不能解释为所有未来比赛都无数据。本轮先对原响应已出现的
销售日值做一次验证，仍返回空；既有 `GetList` 却返回 43 场，15 场在当时距离开球
超过半小时。复用现有 `GetInfo + GetMoreSpInfo` 对已知市场 ID 刷新，取得美国—加拿大：

- `spftll:match:3097883`，开球 UTC 2026-10-07 00:00，即北京时间 08:00。
- 实际报价观察 UTC 19:04:59.643848，常规时间 1X2 为 1.49／4.00／4.80。
- 去水初始概率约为 59.42%／22.13%／18.45%。这只是观测到的市场初态。
- 来源自身报价更新时间未知，未宣称庄家仍可交易。

另外两次官方请求依次读取加拿大足协首页及其中真实出现的 `/match/6630/` 链接。
官方 DOM 的原生 ID、双方顺序、国家图标、成年男子队标识、系列 ID 和明确的
`06 Oct 2026 20:00 EDT` 一致，并与市场初态精确对应。
新增独立版本的 Canada 身份核验，只支持当前实际核实的这场比赛与实体映射，
不宣传为通用友谊赛网关。泛称 `Men's National Team` 仅在受约束官方 DOM 内用于
类别校验，不作为跨网页加拿大队别名。

新来源通过显式 source profile v3 接入；原 v1/v2 输出保留。候选生成显式 v4
识别已观察的官方新闻子域 `news.canadasoccer.com`，只允许从成功准入的协会首页
实际返回链接形成候选。没有把准备阶段看到的文章直接喂给 Actor，也没有按伤病等
主观题材给查询赋值。旧 v1/v2/v3 候选回放保持原版本行为。

## 实际自主获取及其边界

先登记新比赛为 `f_train`，随后使用固定种子 190 和两次请求预算执行现有采集器。
实际轨迹为：

1. Agent 选择 `United States Canada 2026-10-07 match preview` 搜索，来源请求失败；
   失败原始回执与成本保留。
2. Agent 选择官方比赛页，成功读取约 2284 字符、63 个原始链接。
3. 候选菜单由 3 增至 4，预算耗尽后停止，未追加请求。

独立复核确认第二次响应虽为 HTTP 成功，但仍是 `unknown_page_role`，且存在
`response_kind_unknown` 训练排除原因；即使以后取得赛果，也不能自动将这段页面
当作合格正文。新增的一项是导航文本触发的搜索查询，不是发现了新的有用新闻。
本项保留这个失败案例，未修改内容分类或追加预算来制造正向结果。

概率未变，原始整条轨迹零网络精确回放通过。这是未知信息的有限探索，不是已校准
正 VoI 选择；预算停止不能被称为所有剩余信息都无价值。总新 HTTP 为 8 次：
6 次数据准备、2 次 Actor 获取，二者分别记账。

官方比赛身份确认并不确认常规时间赛果。本场独立结算规则仍未知，网关明确返回
PENDING、`regulation_rule=null`，绝不套用 UEFA 欧国联规则或产生标签。

## 当前状态与验收

统一重建全部新旧实际轨迹后，共 7 场独立比赛、10 次运行、28 次真实响应；
独立有标签比赛仍为 1 场、合格监督响应仍为 2 条。
没有事后补历史发布时间、凭预测器拟合结果声称真实收益，或重写旧档案。

最终相关回归 1082 项全部通过。训练入口的 16 项单元与 8 项 raw 集成、36 项
Canada 身份核验以及新官方子域发现检查均包含其中，不重复累加。
构造集成覆盖达到必要支持后的真实 fit/save/load、后续 B 采集与精确回放；
这些测试不计入真实比赛或收益证据。
