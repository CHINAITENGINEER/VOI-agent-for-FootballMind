# 第十一轮：让查询价值对应执行时的同一预测器

本轮研究 Agent 在同一可见证据下选择 `results_view`、`xg_view` 或 STOP，并在真正获得返回后重新评估剩余动作。没有取得的信息和比赛赛果均不进入工具选择。数学估值与停止规则承担数值决策，LLM 不编造信息价值。

预声明设计见 `round11-design.md`，其冻结 SHA256 为 `37e769df19bef0c83fd94efe81ed4cf94aaa0a2591576852758f4e2a8f283663`。正式运行目录为 `var/parallel/baselines/round11/frozen-version-v1/`。所有结论以完整运行及对应独立验收产物为准。

## 核心问题

第十轮显示：旧校准策略实际执行的查询都有足够的历史局部计数，也都落在历史局部 EVSI min/max 内；但生成校准收益的过去 OOF 模型比部署模型更早、更小。因此“在历史范围内”仍不足以证明残差可以迁移到新的预测更新器。

本轮把目标写成

\[
g^*(H,a;\psi)=\mathbb E[\ell(p_\psi(H),Y)-\ell(p_\psi(H,Z_a),Y)\mid H,a,\psi],
\]

其中 \(\psi\) 是完整冻结的基础预测器、联合返回模型、分桶和参数。g 是固定预测更新器获得工具返回后的经验收益，可以为负；它不同于允许忽略新证据的 Bayes 最优信息价值。

## 时间与版本匹配

目标仅采用旧第九轮的外层折 2–6。每一目标折 k 使用原折 k−2 的 joint 工件，完整复制其字节，预测器不重训。在目标折内部，校准、验证和测试始终使用同一个 reference ψ；不同目标折的 ψ 可以不同。

校准候选来自目标折原有 training_match_ids，并要求：预测截点严格晚于 reference 训练截点；该比赛不属于 reference base/joint 训练集；赛果在目标 train cutoff 前可得，且严格早于所有后续验证和测试预测截点。这是“两折提前，约 60 天，再按实际可用性清除”的窗口，不是强制恰好 60 自然日。原目标训练切分排除的比赛保持排除。

两个校准组使用完全相同的比赛和四条合法转换：

- `same_version`：用当前冻结 ψ 重新计算查询前后概率、模型 EVSI 和实际收益。
- `matched_mixed`：取原 round9 前向 OOF 中相同比赛、动作和已获取集合的转换；其生成模型在历史时间块间变化。

缺少完整混合版本对照的比赛从两组共同排除；全部排除 ID 和理由保存在每折 selection 工件。共同集合选择只依据 ID、时间和可用性，未根据收益或赛果类别过滤。

两组执行时均绑定同一个 reference ψ。对照同时改变了生成 EVSI、数值分桶归属及收益标签的预测器，不应把组间差异夸大为一个孤立的模型版本因果效应。

## 保持不变的决策机制

残差估值器直接复用冻结的 `ResidualEVSICalibrator`：EVSI 边界 .02/.05/.10，局部及父层最小支持 12，收缩强度 20，周聚类描述性下界系数 1.64。已取得的缺失返回仍计入动作集合，避免因为数值 mask 未变化而重查。

校准窗口不再做内层 80/20 划分，全部合格窗口样本参与拟合。后续原验证集仅提供诊断，不选择参数、λ、reference 或获胜策略。执行 λ 与原报告效用费用系数统一固定为 **0.5**。预算仍为 0/.02/.03/.05，最多两次请求。

策略为 base-only、all-available、random（原五个种子）、entropy、原 EVSI 一步、matched-mixed-mean、matched-mixed-lcb、frozen-version-mean、frozen-version-lcb。同折全部策略使用同一 reference ψ，主要比较不混入旧轮更晚预测器的得分。

校准策略每步仅判断一次获取的校准收益是否超过当前工具费用，真实返回后再次决策；未将单步 LCB 当成多步计划的置信下界。LCB 是描述性经验均值估计下界，不附带覆盖、环境变化或选择后保证。

## 工件与 Agent 接线

新增 `frozen_version.py` 负责共同窗口、监督身份与版本/时间检查；`experiment_round11.py` 复用原研究 runner 和估值器。旧轮任何源码和工件均保持冻结。

same_version 样本保留 `oof_*` 字段以兼容原序列化类，但新增 `supervision_kind=same_version_heldout_fixed_predictor` 明确它是同一固定模型的训练集外预测，并非不断变化的 OOF 模型。新估值器工件仍使用原 `residual-evsi-calibrator-v1` 类型，新增准确的实验 metadata 后重新计算新工件哈希，便于实际 Agent 工作流读取。

每折包含三个模型工件：冻结 joint、same_version 校准器、matched_mixed 校准器。监督文件逐条保留 before/after、EVSI、收益、生成模型哈希和训练 ID。验证及测试完整转换的真实收益仅保存一次，旁边放两个校准组的估计，明确两组共享同一个 ψ 与赛果。

测试与验证均保存全部九种策略的完整决策轨迹。实际工作流将固定取每折最早的测试比赛，分别运行同版本均值、同版本 LCB、混合版本均值，共 15 个案例；不按查询是否发生或结果好坏选择案例。逐候选值、支持、费用、选择、返回和更新概率由对应 Agent 验收任务核对。

## 正式运行结果

正式工件 `frozen-version-v1/report.json` 为 `OK`。5 个目标折的校准窗口分别有 60、90、104、87、79 场比赛；每组每场四条转换。测试包含 200 场已有历史比赛、10,400 次策略回放；验证包含 213 场、11,076 次回放。产生 10 个新校准器，5 个 reference joint 均为旧工件的原字节复制，没有新增赛果预测器、外部数据请求或 LLM 调用。

## Agent 实际选择与价值估计诊断

在 .05 预算下，同版本均值策略第一步选择 results 60 场、xg 92 场、STOP 48 场；全部 152 次查询后都选择 STOP。它实现了依比赛而变化的第一条信息选择，也真正执行了返回后的再估值，但本次测试没有展现同版本策略的第二次查询。混合版本均值的初始 STOP 为 32 场，148 场查询一次，20 场查询两次；其中 results→xg 有 17 场，xg→results 有 3 场。完整轨迹将取得信息前的选择值与取得后的真实概率更新分别记录。

800 条完整测试转换使用同一个 reference ψ 计算实际收益，平均模型 EVSI 为 **+.049451**，实际查询收益为 **−.013830**。同版本估计均值为 −.018703，混合版本为 −.018668；二者均仍有偏差。相对实际单次收益的均方误差分别为 .105217、.105946，原始 EVSI 为 .106320。同版本的整体 MSE 略低，并未在所有折中一致降低，也没有带来策略效用改善。全转换诊断和实际策略选择的分布不同，整体均值或 MSE 并不充分评价选择后的收益。

同版本完整转换中 763 条使用局部支持、37 条退回父层；混合版本分别为 755 和 45，均无不支持转换。这不证明残差平稳、信息充分或查询后概率校准正确。有限窗口估计、粗粒度 EVSI 分组、返回压缩及旧联合预测器的失配仍共同影响结论。本轮实验只缩小了“校准时和执行时预测器不同”这一设计缺口，并未确认它是此前失败的唯一原因。

真实 Agent 验收已完成：固定的 15 个首场案例通过 37 个候选卡片、23 次预测更新、8 次动作及 311 条审计事件的一致性核对，结果保存在 `var/parallel/agent/round11/frozen-version-bridge-v1/`。三种首场决策 results、xg、STOP 均出现；LCB 的五个固定首场恰好全部 STOP，因此同时报告完整研究中的 4 次查询，避免局部案例代替全量行为。

独立全量研究验收另见 `var/parallel/baselines/round11/frozen-version-v1-verification.json`，状态为 `VERIFIED`：独立重建两组各 1,680 条监督、10,400 次测试与 11,076 次验证回放、1,652 条共享诊断转换、2,912 个公开联合状态及 2,891 次原始 EVSI 决策。17,401 条测试事件与 18,591 条验证事件的实际费用、公开状态、候选估值和停止均被核对。验收证明工件和设计一致，不赋予策略收益统计优越性。正式运行所记录的 11 个实现文件 SHA256 在交付时再次全部匹配。

## 验证与解释边界

6 项新增专项测试通过，覆盖共同 ID 与原训练 purge、混合监督缺失的双组排除、严格结果可用性、完整四转换和重复拒绝、同版本重新生成实际概率与收益、伪造版本/错误收益/错误公开状态拒绝，以及准确 metadata 下的旧类序列化回读。

目标测试包含先前已探索的 200 场比赛，不是新增独立评估。随机种子先在比赛内平均，再等权比较比赛；区间采用既有排序 UTC 周 bootstrap。它不修正历次研究选择、多重比较、拟合不确定性或时间变化。

研究对象是固定两个工具目录内的自主下一步选择和停止，不是发现任意新网站、上线阵容工具或证明 LLM 具有开放环境信息搜索能力。原用户提出的出线、轮换和战术动机尚未加入未经验证的数值特征。
