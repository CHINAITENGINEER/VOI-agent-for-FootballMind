# 第十轮：冻结模型的训练与执行支持审计

本项只诊断第九轮残差校准器在执行时遇到的状态是否有过去数据支持。新增 `support_round10.py` 和独立 JSON 工件，不拟合新策略，不重新估计 q、残差或概率模型，不从旧测试成绩选择阈值。第九轮所有源码与产物保持冻结。

正式工件：`var/parallel/baselines/round10/support-audit-v1.json`，状态 `AUDITED_DESCRIPTIVE`。审计完成并冻结，新增拟合模型数为 0。

## 四个阶段与可比较单位

每个外层时间折分别审计：

1. 残差拟合段 fit：前 80% 的合格前向 OOF 转换，包含已完成的标签时点清除。
2. 独立诊断尾段 diagnostic_tail：后 20% 的 OOF 转换，只诊断，不影响参数。
3. 原外层验证集 outer_validation：由该折冻结的部署 joint 模型重新枚举四条合法转换，赛果须在原 `validation_label_cutoff` 前可用。
4. 测试 test：同一部署 joint 模型重新计算四条转换，并逐条核对冻结第九轮的 EVSI、实际收益和校准收益。

比较单元固定为 action + acquired-action-set + 原 EVSI 桶 `[0,.02)`、`[.02,.05)`、`[.05,.10)`、`[.10,+∞)`。已取得的缺失返回也属于 acquired-action-set。每场四条转换共享一个赛果；不同折的 fit/tail 会重叠，表格计数不应相加当成独立比赛数。

fit/tail 的免费先验 p0 读取已冻结的 OOF 空状态记录，并核对它与该次新 joint 的基础模型工件哈希、版本及 cutoff 对应。两类阶段分别使用过去 OOF joint 与该折部署 joint，所以日历时间、训练规模和模型版本同时变化。

## 完全由公开量构造的支持特征

支持计算只读取 action、已获取集合、当前模型 EVSI、免费 p0、p0 熵、比赛 ID 与公开时间标记。实际赛果和收益只进入单独的 `offline_outcomes` 诊断摘要，未参与范围、阈值或距离计算。有毒对象单测检查 support 函数不会读取结果字段。

每个阶段输出 EVSI、p0 各类别概率、免费先验熵和当前部分观测后验熵的最小值、第 5 百分位、均值、中位数、第 95 百分位与最大值。同时输出产生这些估值的 joint/base 训练比赛数、模型 cutoff、预测时点距训练 cutoff 天数，以及 joint 样本量与该折部署 joint 样本量之比。

支持状态严格沿用冻结校准器：局部支持至少 12 为 `supported_local`，局部不足但 action/acquired 父层至少 12 为 `supported_parent`，父层也不足为 `unsupported_parent`。支持数按比赛去重，不因一场比赛的多个字段或多个随机种子膨胀。

范围检查仅有预声明的两种：fit 的 min/max，以及 fit 的第 5/95 分位。分别在局部桶和父层记录 EVSI 是否落在 min/max 范围，局部另记录 5/95 范围与免费先验熵范围。5/95 本来就会排除分布尾部，即使过程稳定也可能有约 10% 数据落在外面，故不把这一比例自动叫做异常率或漂移率。

p0 距离采用同一局部桶内最近 fit p0 的欧氏距离。对 fit 本身采用 leave-one-match-out，避免自匹配距离必为零；其他阶段只参照 fit。没有额外距离阈值，也没有尝试多个阈值选择结果。p0 的逐坐标 min/max 包络仅是坐标范围，明确不是凸包成员判断，不证明多维联合支持或 p0 的条件充分性。

## 实际执行查询与完整转换分开

完整测试转换包含全部四个合法状态—动作组合，不代表它们真的被查询。本审计另读取冻结真实轨迹，只在有 `charged_cost` 的事件中记录实际执行查询；仅关注 calibrated-mean 与 calibrated-lcb，按四档预算分别汇总。

原第九轮新策略是确定性的，每场每预算一条轨迹。通用计数仍保留逆种子数权重，避免未来重复轨迹被视作新增独立数据；不同预算使用同一批比赛，也不能合并为独立观察。实际查询摘要报告执行次数、唯一比赛数、唯一状态—动作数，以及落在 fit 范围外、局部/父层低支持、p0 坐标包络外的比例。没有查询时比例为 null，不伪造为“全部在支持内”。

## 解释边界

有足够局部支持、落在历史 EVSI 范围内、p0 数值相近，是三个不同的描述。它们均不单独保证残差校准准确；反过来，落在范围外也不直接证明一次查询必然有害。

在本历史滚动实验中，时间推进时 OOF joint 的训练样本量、p0 基础模型和分桶边界也随之变化。阶段间分布差异可能同时与模型估计误差、训练规模、赛季构成或时间变化有关。本诊断不识别各项原因，尤其不把差异直接归因于 concept drift。

足球数据及可用时间仍属于离线重构；赛前真实发布、供应商失败机制与开放新闻采样不在当前数据中。测试仍是已反复使用的 290 场比赛，这项支持审计没有提高其独立验证等级。

## 验证与复跑

6 项专项测试覆盖：支持函数不读取结果或隐藏 payload；nearest-p0 对 fit 排除同场自匹配；min/max 与 5/95 分位分开；已获取缺失上下文与固定桶边界保持独立；重复支持与非法 p0 被拒绝；声明训练 cutoff 与预测时点可以相等，但实际训练标签必须严格更早。

初次审计在第 2 折遇到声明 cutoff 相等的合法场景时触发了过严的审计门禁，未写出正式结果。修正后的检查把声明 cutoff 与实际训练标签时点分开，记录保存在 `support-audit-attempt1.json`。此修复只涉及新增审计器，旧模型、校准器、数据与参数均保持原样。

## 正式支持审计结果

完成七折，核对 60 个冻结模型工件。四个阶段分别包含 fit 10,888 条、独立诊断尾段 2,776 条、外层验证 1,092 条、测试 1,160 条转换。前两者跨折重叠，验证和测试也在滚动时间切分下复用比赛；测试的独立比赛数仍是 290。

全部 1,160 条测试转换均为 `supported_local`，局部独立比赛数范围为 **30–270**。按各自 action/acquired/bin 的 fit 参考：

| 检查 | 范围外转换数 | 比例 |
|---|---:|---:|
| 局部 EVSI min/max | 17 / 1,160 | 1.47% |
| 父层 EVSI min/max | 0 / 1,160 | 0% |
| 局部 EVSI 第 5/95 百分位 | 124 / 1,160 | 10.69% |
| 局部免费 p0 熵 min/max | 50 / 1,160 | 4.31% |

完整转换中的局部范围外状态，不等于实际执行的查询。对原第九轮校准均值策略：

| 预算 | 实际查询 / 唯一比赛 | 局部 EVSI min/max 外 | 局部 EVSI 第 5/95 百分位外 | 局部支持不足 | p0 坐标包络外 |
|---|---:|---:|---:|---:|---:|
| 0 | 0 / 0 | 无查询 | 无查询 | 无查询 | 无查询 |
| 0.02 | 53 / 53 | 0 | 3（5.66%） | 0 | 1（1.89%） |
| 0.03 | 128 / 128 | 0 | 7（5.47%） | 0 | 6（4.69%） |
| 0.05 | 128 / 128 | 0 | 7（5.47%） | 0 | 6（4.69%） |

校准 LCB 在所有预算下均无查询，范围外比例保留为 null。两个 128 查询集合属于重复预算回放，不新增 128 场独立数据。

因此，本审计不支持把已执行查询的净收益不足主要解释为粗糙的 EVSI 范围外推或局部计数不足。这个结论很有限：落在一个标量范围内并不保证联合状态得到充分表示，30–270 个局部样本也不等于条件均值估计精确，更不验证残差关系随时间保持不变。

## 下一项可检验设计：先固定预测器版本，再收集校准收益

把待估对象显式写成

\[
g^*(H,a;\psi)=\mathbb E\left[\ell(p_{\psi}(H),Y)-\ell(p_{\psi}(H,Z_a),Y)\mid H,a,\psi\right],
\]

其中 \(\psi\) 标识固定的完整预测更新器版本，包括免费先验、联合返回模型、分桶和参数。它估计该版本在获得工具返回后的预测更新收益，仍可为负；它不是允许忽略证据的 Bayes 最优信息价值。

一个直接的前瞻实验顺序是：

1. 在时点 T0 仅用过去可得数据拟合并冻结 \(\psi_0\)，保存其完整哈希。
2. 在随后独立的校准窗口 C 中，用同一个 \(\psi_0\) 记录查询前估值与工具返回后的概率；待这些比赛的结果实际可用，再构造收益和拟合校准器。
3. 进入更晚的验证窗口 V，继续保持 \(\psi_0\) 和已拟合校准器固定，按预声明规则选择执行费用权重。
4. 在更晚的测试窗口 T 中运行全部策略，包括 base-only、全部获取和校准策略；所有策略使用同一个 \(\psi_0\)，查询前后仅改变可见证据。

这样，收益监督不再由一串训练规模不断变化的 OOF joint 生成后迁移到另一套部署 joint。比较的是同一预测更新器下的获取策略差异。它仍会面对 C、V、T 之间的环境变化和有限样本误差，所以不附带校准或收益保证。

若随后更新为 \(\psi_1\)，应建立新的版本化校准与评估周期。模型版本更新带来的收益，需要在相同可见信息条件下另行比较，并遵守各自训练数据的时间边界；不把它混入“查询新信息”的收益。现有 290 场旧测试也不因此变成新的独立评估。

这只是下一项可检验研究设计，本轮没有执行上述前瞻实验、产生新结果或证明理论保证。当前支持审计也不支持增加一个仅按 EVSI min/max 拒绝查询的临时门槛。
