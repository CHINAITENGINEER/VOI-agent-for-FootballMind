# Round 11: autonomous acquisition with a frozen prediction-update version

Design recorded on 2026-09-26 before running this contrast. All test games have
already been explored; this is a matched diagnostic experiment, not independent
confirmation. The research objective remains choosing the next information
source and stopping as a function of currently visible evidence.

## Estimand and controlled contrast

For a fixed prediction/update implementation and artifact psi, estimate

    g*(H,a;psi) = E[loss(f_psi(H),Y) - loss(f_psi(H,Z_a),Y) | H,a].

The existing two-action Agent chooses results_view, xg_view, or STOP. After an
actual return it updates visible information and evaluates remaining actions
again. An unpurchased return and the final outcome do not enter tool choice.
This evaluates adaptive information choice from a fixed catalog. It does not
establish autonomous discovery of new websites/tools or live LLM reasoning.

Compare two calibrators sharing the same deployed psi, calendar calibration
matches, action/state transitions, residual estimator, cost and test games:

1. same_version: use that exact frozen psi to generate held-out pre/post-query
   probabilities, model EVSI and realized update-gain labels.
2. matched_mixed: reuse the already verified round-nine forward-OOF transitions
   for the exact same match/action/acquired-set identities. Those transitions
   were generated by changing earlier OOF predictor versions.

Both calibrators are deployed against the same frozen psi. This isolates a
matched change in the generator of EVSI and gain labels; it does not separate
every effect of model age, model size or temporal drift, and is not a guarantee
that same-version estimation is superior.

## Temporal protocol

Use original outer target folds k=2,3,4,5,6. For each k, copy the exact frozen
round-nine joint predictor from reference fold k-2, including its embedded base
predictor, return quantiles and parameters. No predictor is retrained.

The calibration candidates are the target fold's original training match IDs
whose prediction_cutoff is strictly after the reference predictor training
cutoff. This gives a roughly two-fold (60-day) post-freeze calibration period,
with the original availability purge. Actual calibration labels must be
available by the target train cutoff and strictly before every following
validation/test prediction cutoff. Reference base/joint training IDs are
excluded. If a complete four-transition mixed-OOF counterpart is missing,
exclude that match from both arms and record why. Selection uses times,
identities and availability, not gains or outcomes.

Use all retained calibration matches in each arm; no further 80/20 split is
introduced in this small held-out window. Original target validation partitions
are diagnostic only; do not fit parameters or select lambda there. Original
target test partitions remain unchanged: five folds and 200 previously explored
matches. Earlier target folds are excluded by the fixed two-fold requirement,
not their scores. Each fold has one psi held fixed through its calibration,
validation and test phases; psi may change between folds.

Same-version samples retain the compatible legacy oof_* provenance fields, but
their metadata must explicitly identify same_version_heldout generation. The
reference model was trained before every calibration prediction and excluded
these matches. This is out-of-training prediction from one fixed artifact,
not a claim that several OOF model versions were used.

## Prespecified estimator, costs and policies

Reuse the frozen residual formula and metadata contract. EVSI edges are
.02/.05/.10, local/parent minimum support12, shrinkage20 and descriptive risk
multiplier1.64. Cells condition on action/acquired-set/EVSI bin, with parent
fallback. A returned missing value is still an acquired action. No thresholds
or features are chosen from this run's gains.

Both execution lambda_money and the reporting utility weight equal the already
fixed alpha=.5. Physical budgets remain 0/.02/.03/.05, at most2 requests. All
costs remain simulated frozen projections. Independent mean-estimation lower
summaries have no new coverage guarantee.

Nine strategies:

- base-only
- all-available
- random, existing five seeds
- entropy, existing threshold
- evsi-one-step, fixed lambda=.5
- matched-mixed-mean
- matched-mixed-lcb
- frozen-version-mean
- frozen-version-lcb

Use the same predictor for every strategy within the fold. Expected test runs:
200 matches ×4 budgets ×13 effective strategy/repeat combinations =10,400.
Validation is reported without selecting a winning policy. The primary budget
remains .05, with all other budgets retained.

Primary comparisons are frozen-version-mean versus matched-mixed-mean and
base-only. Secondary comparisons include all-available, entropy, random,
raw one-step EVSI and the conservative counterparts. Average random seeds
within each match before equal-match comparisons. Use the established sorted
UTC-week bootstrap, 2,000 draws and seed1729. Intervals remain descriptive and
omit repeated-research, fitting and multiplicity uncertainty.

## Agent behavior evidence

Keep actual query trajectories and complete offline transition diagnostics
separate. Report initial STOP rate, results/xg first-choice proportions,
0/1/2-query distributions, probability changes and costs. The following
behavioral question is central: with the same catalog and budget, does the
Agent choose different next actions as its public evidence state changes?

Run actual Agent workflows on each target fold's first scheduled test match
(kickoff then ID, no performance filtering), for frozen-version mean/LCB and
matched-mixed mean. Verify all candidate values and selected actions against
the research traces. Decision cards must come directly from those actual
workflows: current probabilities, visible masks, expected query gains, support,
costs, selected action/STOP, receipt and updated probabilities. If these fixed
cases all stop, report it rather than selecting more favorable cases.

Use aggregate trajectories to describe action heterogeneity; this alone is
not causal proof of improved decisions. The LLM is not asked to invent numeric
value estimates. The present experiment tests the mathematical information
selection core used by an Agent.
