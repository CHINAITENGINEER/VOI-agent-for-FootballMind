# 第十三轮：具体返回内容是否改善下一次查询

本轮进一步收窄问题：在同一场比赛的基础预测、已获取工具集合和剩余预算完全相同时，工具实际返回的内容是否改变下一次查询或 STOP，以及保留这种内容依赖是否改善实际效用。

运行前设计为 `round13-design.md`，SHA256 `dc26af59df5fc7533130c48a2767e643a7d86835f8b8610c16c71ac724309054`。正式目录为 `var/parallel/baselines/round13/content-marginal-v1/`。这是此前 200 场比赛上的探索性延续，没有新增独立测试比赛。

## 控制的变量

第十二轮的 stage-prior 对照删除了当前比赛的基础概率和返回内容，因而与条件估值同时存在多处差异。本轮保留每场免费上下文形成的同一基础概率 `p0`，保留已获取集合 `S`，保留同一个赛果预测器及同版本残差校准器；只在查询价值计算中抹去已获取工具的实际内容。

新策略 `content-marginal-mean` 在 `S` 为空时直接保留原条件估值数值。因此原策略第一次查询哪个工具、还是直接 STOP，都应完全相同。

如果已经获取工具 `b`，剩余动作是 `a`，新值为：

\[
\bar g(a;p_0,\{b\})=\sum_z P_\psi(Z_b=z\mid p_0)\,\hat g(a;p_0,Z_b=z).
\]

其中每一个分支先用冻结 joint 模型计算剩余动作的 EVSI，再用原校准器的 EVSI 桶和历史残差校正得到经验预测更新收益，最后加权。将平均 EVSI 送入校准器是另一种估值器，本轮测试专门验证二者的区别。

权重来自清空全部付费组后的免费 joint 分布。它不依赖该场实际已获类别、更新后后验、尚未获取工具的真实返回或赛果。所有正概率类别均参与，包括 missing-summary。任何正概率分支缺乏支持就将整个候选标记为不支持并 STOP，既不丢弃分支，也不重归一化。

两个工具的有限类别最多产生十个分支，采用精确有限求和，没有抽样、新拟合或参数搜索。源模型的返回分布仍可能失配，因此该控制不是对真实世界所有可能信息的无误积分。

## 实际预测与内部假设严格分开

估值器内部类别分支只用于计算“如果不使用实际内容，对同一比赛的下一步价值应如何平均”。这些分支从未成为工具返回、观测证据或实际费用。执行策略依旧由历史环境揭示真正的工具投影，并将它交给原 joint 预测器更新赛果概率。

序列化类型为 `content-marginal-gain-v1`，显式绑定原 joint 和原 same-version 校准器各自的版本、文件 hash 和时间信息。wrapper 顶层 `model_evsi`、`evsi_bin`、`lower_gain`、`upper_gain`、`standard_error`、`uncertainty` 均为 null；模型分支 EVSI 的平均另记为 `marginal_model_evsi`，避免把它与最终校准后的经验收益混淆。每条分支保留概率、类别、EVSI、原校准估计与支持。

各分支的支持数最小值只作为保守诊断摘要，不表示新独立样本量；没有计算聚合置信区间。源分支已有的周标准误保留在 audit 中，不被组合成多步或分布变化保证。

运行入口继续拒绝假设 token、提供方失败、未来可用时间、重复已购动作和非法状态。缺失返回确实属于已取得集合。实际模型中的缺失摘要和 API 超时保留不同语义。

## 共同数据、费用与验证

复用第十一轮目标折 2–6 的五个 joint 和五个 same-version 校准器，原字节复制到新目录；生成五个只描述绑定与计算规则的 wrapper。训练集合、验证和测试 ID、全部分桶及参数保持原值，费用 results=.02、xg=.03，最多两次请求，四预算 0/.02/.03/.05，λ 与效用费用系数固定 .5。

预声明主比较为 `.05` 预算下原 `frozen-version-mean` 减新 `content-marginal-mean` 的效用损失，定义为 `LL + .5 × money`。负差表示原条件策略较好。按同一比赛配对，随机参考策略先在比赛内平均种子，再等权比赛；采用排序 UTC 周 bootstrap 2,000 次、种子 1729。

新增回放只执行一个新策略：800 次测试、852 次验证。第十一轮与第十二轮原策略只读引用，source manifest 绑定其文件 hash。验证用于描述，不选择策略或调整参数。

runner 强制验证首动作和初始预测逐场相等、原始初始 STOP 保持 STOP；预算低于 .05 时第二次查询均不够费用，所以完整动作、费用、最终概率和损失应与原策略精确相同。全量轨迹保留候选分支 audit 和真实返回后的预测。

9 项新机制测试通过：初始数值及动作精确一致；分支校准先于积分；missing 类别保留；免费 prior 权重与真实内容及隐藏载荷无关；任一正质量不支持使整体停止；source-missing 已获取状态和错误集合拒绝；运行 token、失败、时间、非法动作与 mean-only 边界；不可负担后续动作的 STOP；源模型与校准器双重 hash/版本绑定及损坏工件拒绝；分支概率完整归一化与非负检查。

真实 Agent 固定选择每折最早测试比赛，共五个新工作流，引用相同比赛的五个旧条件策略案例。独立全量数值验收与每场两种第一工具的内部类别分支分析由根任务生成，区分全部合法历史、实际访问历史和模型假设类别。

## 正式策略回放结果

正式工件状态为 `OK`：800 次新测试、852 次新验证回放均完成，没有新增拟合。五个 joint 和五个源校准器均为原字节复制，五个 wrapper 只描述绑定及边缘化计算。记录的 15 个实现文件 SHA256 在运行完成后再次全部匹配。

新策略与原条件均值策略在 **所有测试与验证回放中均产生相同动作路径**。预算 .05 的结果如下：

| 策略 | Log loss | 平均模拟费用 | 实际查询总数 | 效用损失 |
|---|---:|---:|---:|---:|
| base-only | 1.109339 | 0 | 0 | 1.109339 |
| tool-prior-mean | 1.116457 | .01200 | 80 | 1.122457 |
| stage-prior-mean | 1.119416 | .02155 | 170 | 1.130191 |
| frozen-version-mean | 1.121521 | .01980 | 152 | 1.131421 |
| content-marginal-mean | 1.121521 | .01980 | 152 | 1.131421 |

预声明主比较的 log loss、费用和效用损失差均为 **0**，对应周 bootstrap 区间均为 **[0, 0]**。这里的退化区间来自每场实际配对差本身都是零，不是对总体等效的统计证明，也没有证明更换赛季、价格、预测器或工具后仍相同。

全预算保留相同结论。测试中零预算 200 场全部 STOP；.02 预算查询 results 87 场、STOP 113 场；.03 和 .05 均查询 results 60 场、xg 92 场、STOP 48 场。每次实际查询后都 STOP。800 次测试首动作全部相同，其中 600 次低预算回放的动作、费用、最终概率及损失精确一致；其余 200 次最大预算也没有路径差异。

验证中零预算 213 场全部 STOP；.02 预算查询 results 93 场、STOP 120 场；.03 和 .05 均查询 results 74 场、xg 89 场、STOP 50 场。852 次验证首动作全部相同，639 次低预算完整数值相同，最大预算同样没有路径差异。最大预算的两策略验证效用损失均为 1.132974。验证没有用于更改边缘化规则或另选成本。

该结果直接限定了本轮可以主张的内容：在这个冻结预测器与校准器、既定成本、已探索历史的实际政策访问路径上，抹去第一次真实返回内容后，下一步决策没有改变。因此本轮未观察到保留这些内容带来的策略效用增量。即便后续内部类别分析发现某些假设类别会让原条件估值改选，也应同时保留本段实际路径结果；内部敏感性不替代实际政策增益。

真实 Agent 的五个固定首场案例已通过，见 `var/parallel/agent/round13/content-marginal-bridge-v1/acceptance.json`：13 个候选、8 次初始或真实返回后概率、3 次实际历史揭示、.08 模拟费用和 109 条审计事件一致。28 个数学分支单独标为 model-only，未计入三次实际动作或工具 receipt；13 张候选卡片保存这种区分。首轮候选收益与第一动作逐项匹配旧条件策略卡片，全部 native branch 数值匹配研究轨迹。Agent 新增专项 22 项及含旧轮的合并回归 84 项通过。独立全量研究验收另由根任务报告。

## 解释边界

合法但未访问的状态和假设类别不是新增比赛或实际查询。任何假设返回都不会配上这场原赛果后被声称为真实的反事实收益。内部类别敏感性只证明该估值机制在冻结模型内会随内容变化；策略回放的收益才评价本次保留这种变化的效果，两者分开报告。

本轮成本为模拟费用，两种工具仍是同一缓存数据来源的两个投影，返回压缩存在信息损失。置信区间未涵盖拟合、历次研究选择、多重比较和分布变化的不确定性。旧历史上表现接近或区间跨零不代表已证明等效，更不构成开放环境迁移结论。
