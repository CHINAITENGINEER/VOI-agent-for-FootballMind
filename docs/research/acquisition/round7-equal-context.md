# 第七轮：给所有策略相同免费上下文后，信息获取还剩多少收益

正式研究产物：`var/parallel/baselines/round7/equal-context-v1/`。
证据等级：已探索历史赛季上的时间滚动探索，非独立前瞻确认。

## 修正的问题

第六轮值模型能读取球队身份、比赛日期和已取得的证据，但空 mask 的赛果模型仍使用同折频率先验。因而一部分收益可能源于基础预测没有利用已经免费可见的信息。第七轮将同样的免费 fixture 上下文接入所有策略、所有 mask 的赛果模型，重新回答主动获取的增量问题。

免费上下文仅包括 exact Understat source team/competition identity、开球日历的周期编码与预测提前时间。真实小组出线形势、阵容、轮换、战术意图不在当前英超导出中，未虚构这些变量。身份映射是离线重建的结构性等价关系，不证明历史时点已经完成核验。

## 方法与可复现边界

`ContextualPartialPredictor` 训练 8 个独立的部分信息多项逻辑回归。空 mask 也使用相同免费上下文；其他 mask 加入相应已经观测的数值。每个头的类别词典、缺失值均值和标准化只使用训练段。未知身份使用零 one-hot 效应，并在输出显式记录。正则化 10、优化器配置在实验前固定，没有依据测试结果搜索。

值模型仍采用第六轮固定岭回归和正则化 20，比较 no-context、prediction-only、source-identity 三个特征集。来源状态属于所有模型共有的公开获取状态；未查询与查询后 source_missing 不混为一类。lambda 在每个时间折的验证集，按固定 `log_loss + 0.5 × 模拟费用` 选择。训练与校准段保持比赛隔离和标签可用时间隔离。

预测器变化意味着旧 OOF 增益标签失效。第七轮从头拟合 24 个 OOF 预测器，重新生成 2,880 条增益转换，涵盖 720 个独立目标比赛；每个目标的预测器只在它的预测 cutoff 之前训练。记录中保存前后概率、已执行 action IDs、OOF 训练 ID、as-of 与模型哈希，便于独立逐条复算。

外层仍为 760 场输入、同一 290 场测试比赛、7 个时间折、24 小时提前量、2 个模拟获取动作、4 档预算。参考策略包括 base-only、all-available、entropy、fixed-order、random。random 保留 5 个固定种子，统计时先在比赛内平均种子，然后等权比赛；随机种子、mask、预算或动作数不增加独立样本量。

总计 13,920 次策略回放，52 个模型工件：24 个 OOF 模型和 28 个外层模型。没有复制前轮预测、增益标签或参考策略轨迹，没有新 HTTP、数据库写入或 LLM 调用。

## 预算上限 0.05 的正式结果

| 策略 | Log loss | Brier | 平均模拟费用 | 平均动作数 | L + 0.5 cost |
|---|---:|---:|---:|---:|---:|
| base-only | 1.080229 | 0.651452 | 0.000000 | 0.000000 | 1.080229 |
| all-available | 1.074565 | 0.647628 | 0.050000 | 2.000000 | 1.099565 |
| entropy | 1.076625 | 0.647309 | 0.034138 | 1.413793 | 1.093694 |
| fixed-order | 1.074565 | 0.647628 | 0.050000 | 2.000000 | 1.099565 |
| random，比赛内平均5种子 | 1.074565 | 0.647628 | 0.050000 | 2.000000 | 1.099565 |
| contextual-no-context | 1.082343 | 0.652732 | 0.007862 | 0.262069 | 1.086274 |
| contextual-prediction-only | 1.078721 | 0.651553 | 0.008172 | 0.337931 | 1.082807 |
| contextual-source-identity | 1.078328 | 0.649986 | 0.013414 | 0.568966 | 1.085035 |

在最高预算下 random、fixed-order 与 all-available 最终都取得全部两个投影，所以最终概率相同。这个等价来自受控环境，没有证明随机策略适用于真实开放信息获取。

source-identity 相对 base-only 的 Log loss 差为 **-0.001901**，按 UTC 周配对 bootstrap 的 95% 区间为 **[-0.022869, 0.021790]**。固定费用换算后的损失差为 **+0.004806**，区间 **[-0.016205, 0.028720]**。当前证据未显示主动获取在相同免费信息基础上获得可靠增量；点估计的少量预测收益没有抵消费用。

相对 entropy，source-identity 的 Log loss 差为 **+0.001702**，区间 **[-0.016310, 0.019287]**；固定效用损失差为 **-0.008660**，区间 **[-0.026643, 0.009175]**。费用下降与预测损失变化应同时报告，尚无非劣性、同质量节费或优势结论。

相对 all-available，source-identity 的 Log loss 差为 **+0.003763**，区间 **[-0.019170, 0.023895]**；固定效用损失差为 **-0.014530**，区间 **[-0.037521, 0.005348]**。

这些区间没有多重比较、此前反复探索、策略拟合或长时间依赖修正。第六轮和第七轮更换了赛果预测器及 OOF 目标，不应将两轮策略分数直接相减解释为单一因果效果。

## 对项目创新的含义

每个时间折中，空 mask 概率已有 35、55、50、42、37、30、41 个不同向量。prediction-only 的初始值估计也分别产生同样数量的不同向量；no-context 仍每折只有一个。因而“跨比赛价值不同”已经不再依赖一个忽略免费上下文的基础预测器。

真正需要正视的是：使用相同免费信息后，本数据集上获取历史结果/Elo/近期状态和 xG 投影的边际收益很小。它们可能与已学习的球队身份信息高度重叠；也可能受样本量、估值误差、基础模型失配和重建数据质量限制。当前实验不支持把任意一个解释认定为唯一原因。

下一步应优先取得能在赛前真实改变条件分布的证据与发布时间：官方首发、已确认轮换、明确的晋级条件、可信的训练/伤停变化等。围绕同一场比赛的证据到达过程，检验“是否值得查下一条、查哪条、何时停止”，并保留同样免费上下文的强参考策略。单场 3:0 或最终平局不能直接充当某条赛前信息价值的标签。
