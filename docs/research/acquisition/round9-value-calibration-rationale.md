# 第九轮的估值目标、校准边界与可检验假设

日期：2026-09-26。本轮设计在新策略测试结果出现前确定。旧290场已经被反复查看，本轮结果仍用于探索与回归，独立确认须使用新时间段。

## 校准的量

设H为当前已取得信息，a为查询动作，Z为未知工具返回，f_H为固定预测器在H上的预测。实际执行这套更新机制的条件期望收益为：

\[
g^*(H,a)=\mathbb E_{P^*}\left[
\ell(f_H,Y)-\ell(f_{H,Z},Y)\mid H,a\right].
\]

这里P*是真实环境，g*可以为负：更新器可能误用新信息。它区别于允许最优决策者忽略新证据的经典Bayes信息价值；后者在免费、最优决策等前提下非负。系统本轮估计的是**当前预测更新机制的增量收益**，不把某模型更新失败解释成信息本身必然有害。

第八轮的模型内部EVSI记为v_q(H,a)，它按拟合联合分布q积分，并满足模型内互信息恒等式。我们在严格前向OOF轨迹上得到实际单场收益g_i和残差r_i=g_i-v_q(H_i,a_i)，学习残差均值，再形成：

\[
\widehat g(H,a)=v_q(H,a)+\widehat{\mathbb E}[r\mid a,A(H),b(v_q)].
\]

A(H)是已经取得返回的动作集合，包括source_missing；它不是只表示数值特征存在的Boolean mask。b是预先固定的EVSI分桶，边界0.02、0.05、0.10，右侧包含等值边界。校准不改变冻结的第八轮预测器、分桶、核带宽或联合返回分布。

每个(action,acquired-set)父组，同一比赛最多一条转换。局部桶至少12场时，其残差均值按n/(n+20)向父组收缩；局部不足12场时完全退到父组，并显式报告局部支持不足。父组不足12场，动作估值不获支持。以上数字未由本轮测试成绩选择。

## 两个停止规则

均值策略比较 `g_hat - lambda × cost` 和STOP的0值。经验保守策略比较 `g_hat - 1.64 × SE - lambda × cost` 和0值。负收益不截断成0，预算仍由独立物理账本约束。

SE以UTC周聚类计算收缩残差均值的不确定性。局部样本属于父组，两个均值的误差相关，因此先合并每场对收缩均值的影响，再按周求和；不会把局部和父组的两个标准误当成独立量相加。仅一个时间块时不生成经验下界，保守策略停止。

这个下界是描述性经验估计，不是单场收益的预测区间，也不是联合模型参数的Bayes可信区间。周数有限、收缩偏差、不同OOF模型带来的分布变化、后续选择行为和比赛间依赖均可能影响它。固定1.64不等于已验证单侧95%覆盖。

本轮仅把该校准用于一步动作。先查某信息后再根据结果选择后续动作，是另一个收益目标；将单步校准值或下界直接加成“二步计划保证”没有依据。第八轮原始一步/二步策略保留为对照。

## 时间顺序与公平对照

新OOF收益必须来自新OOF联合模型：每个chunk使用当时已经有结果且拥有更早OOF基础预测的样本拟合q，基础预测器也来自同一时点以前。原第七轮只复用未改变的空状态p0，不复用它的旧delta；外层第八轮模型保持字节一致。

每个外层训练段的OOF记录按时间切分，前80%拟合残差均值，后20%仅诊断。按kickoff分组，跨过诊断段首次预测截止时间才可用的训练标签被purge。诊断段不用于调桶边界、收缩系数或成本系数；成本系数仍在原独立validation段按固定网格选择。

所有新旧策略的基础信息、实际预测器、工具费用、最大预算和可用返回一致。随机重复先在每场内平均。主要对照包括STOP、全部获取、熵阈值、原始模型EVSI和新残差校准的mean/lcb策略。

预先固定主要预算0.05及效用 `Log loss + 0.5 × 模拟费用`；同时完整报告0、0.02、0.03预算，不按测试成绩挑主结果。未将“少查”单独作为成功指标：一律停止即可少查，因此必须对照免费信息基线并观察同等信息条件下的概率损失。

## 可以检验的假设与尚未满足的条件

H1：残差校准使未参与残差拟合的时间段中，估计收益与实际平均收益更接近。检验每个固定动作/已购状态/估值桶的均值偏差，而不要求某一场结果与期望值同号。

H2：校准后的停止规则降低原始EVSI策略的成本调整损失。若它仍劣于免费信息基线，则只能说明减少部分误用信息，不能称为发现正收益信息。

H3：经验保守规则减少估值过高的查询，同时保留确有支持的收益。若它全部停止，这个行为可以正确反映证据不足，但没有建立自主查询优越性。

一个简单的条件推导说明需要什么证据：如果对当前所有可行动作，包括STOP，均有 `|g_hat(a)-g*(a)| <= epsilon`，且成本已知，则用估计净收益选最大动作，其单步净收益regret至多2epsilon。证明是对真实最优动作和估计最优动作分别应用误差界，再使用后者的估计值不小于前者。若使用真正有效的统一下界L(a)，仅在L(a)>cost时获取，则在该界成立的事件上净收益为正。

这只是列明假设的推导，不是本轮算法已经满足的保证。粗分组残差均值、周聚类SE和测试平均改进，都不足以证明对所有当前状态/候选动作的统一误差界；选择后的子群也可能失配。

因此后续更有研究价值的目标是：围绕实际会选择的动作及停止边界，控制决策相关误差；处理稀疏上下文、漂移与不同来源依赖；在新时间段检查支持和拒绝机制。单纯提高预测器ECE或返回分布似然，并不自动校准查询的增量收益。

## 文献边界

[Zhao等，NeurIPS 2021](https://papers.nips.cc/paper/2021/hash/bbc92a647199b832ec90d7cf57074e9e-Abstract.html)已经研究面向下游决策的校准及有界动作集条件。因此“把校准用于决策”本身不是新主张。本轮实现是特定查询更新收益的粗分组残差基线，没有实现该文的完整算法或继承其理论保证。

[Tang、Sloman、Kaski，AISTATS 2026](https://proceedings.mlr.press/v300/tang26d.html)在Bayesian实验设计/主动学习中分析模型失配与误差放大。它与本项目共同提示：只追求模型内部信息量可能不足。该文研究的训练采样过程与本项目的单个实例信息获取不同，不能直接移植其效果结论。

[von Kleist等，JMLR 2025](https://www.jmlr.org/papers/v26/23-1635.html)讨论时间变化特征获取的离线评价和行为策略改变后的分布变化。当前完整历史投影使我们能枚举模拟返回；真实选择性查询日志的反事实评价仍需额外的可识别性和支持假设，人工采集且propensity为空的记录没有自动获得这些条件。
